本次目标对话片段，以及基础抽取已经提出的 Semantic changes。

## 证据边界

- 目标对话片段是唯一可写证据。新事实必须由目标片段本身可靠表达。
- 邻近上下文只用于理解目标片段中的指代、纠错对象、发言者归因和“此前哪里搞错了”。
- 不得仅因为邻近上下文中出现了一个值得记忆的事实，就把它作为新事实再次写入。
- retirement 只能精确引用输入实际展示的 `[Mxxx]`；未展示或无法唯一定位时不要猜测。
- 基础抽取只是候选。你可以保留、合并、删除或补充其中的变化，但输出必须是最终完整列表。
- 目标片段中引用、检索或复述的旧消息仍是旧证据，不能因为出现在目标片段就重新写入、恢复或强化用户事实；此规则适用于普通和内心会话。AI 对用户的猜测不是用户新表达。同段用户真实的新纠正仍正常处理。
- 例如目标片段只有 AI 回顾“用户以前住上海”，现有信息是杭州，用户没有新确认，则不新增上海事实。若用户当前明确说搬到苏州，才按这个新表达处理相应更新。

## 纠错规则

- 用户明确纠正先前陈述时，可以撤回冲突的旧 Semantic，并在目标片段给出替代事实时写入替代。
- AI 明确承认自己此前理解错误时，可以撤回由该错误解释形成的旧 Semantic。
- AI 的新推断不能推翻用户明确陈述且尚未被用户或可靠目标证据否定的事实。
- 无法确定纠错主体、被纠正对象或替代事实时，保留尚无依据撤回的旧事实。每一条拟新增事实仍须独立审查。
- 标为 `user` 的新事实必须能指出目标片段中用户亲述或明确确认该项的表达；部分认同只支持对应的项。移除仅由 AI 的评价、猜测或旧话复述支撑的用户断言。符合长期准入条件的 AI 自身承诺标为 `agent`，写清主体。
- 对每条拟新增的事实，核对它以后会怎样帮助理解用户或 AF、遵守约定或作出判断。保留有原话依据的长期变化，以及明确打算在以后同类场景采用的做法，写清适用范围和原话的语气。
- 如果一项内容只用于继续当前工作、找回作品、准确引用资料或避免重复发送，移除这项新增候选。事实里混有长期约定和本次执行细节时，只留下约定；一次命名、一次授权或一次操作不足以形成长期规则。独立判断目标片段是否支持撤回已展示的旧事实。
- 每个 retirement 和 new fact 都必须给出简短 reason。新事实的 reason 说明表达依据及长期价值。`speaker_origin` 只能是 `user` 或 `agent`。
- 一个概念变化放在同一个 change；互不相关的变化分开。同一 `[Mxxx]` 不能重复 retirement。

只输出 JSON，不要解释或代码围栏。唯一允许的顶层字段是：

{
  "semantic_changes": [
    {
      "retirements": [
        {"target_ref": "M001", "reason": "目标片段明确说明该旧事实不正确"}
      ],
      "new_facts": [
        {
          "statement": "用户当前确认的替代事实",
          "importance": 0.6,
          "speaker_origin": "user",
          "reason": "替代事实由目标片段明确表达"
        }
      ]
    }
  ]
}

若目标片段最终不应产生任何普通 Semantic 变化，返回 `{"semantic_changes":[]}`。
