# 检查和维护 AF 记忆

先明确用户关心的对象和范围。检查一条错记时，从那条事实查起。检查一批记忆时，说明检查了哪个实例、哪些层、多少条，哪些只是抽样。只检查时给出发现；用户要求纠正时，依据已给出的授权和可用入口继续处理。

核对记录时按下面的路径取用资料。AF 从本轮已激活技能的只读资源范围打开这些文件，Codex 从本文件所在目录打开同一相对路径。

1. 定位条目或寻找原话时，读[查看记忆与核对来源](references/inspect.md)。全量检查按其中的逐条记录与续查方法覆盖用户指定的库存。
2. 判断每条记忆或拟写入正文时，读[记忆质量判据与案例](references/quality.md)。分别判断来源、长期价值、层级与当前状态。
3. 用户要求纠正、撤销或合并时，读[修改与核验](references/correct.md)。核对目标与关联记忆，按需修改后查回来源并读回实际状态。

全量检查持续到清单中的每个 ID 都有判断和理由。用户要求修改时，继续落实已确定且可执行的调整并核验。遇到单条缺证或能力不足，记录该条待核或待执行及原因，继续其他条目。结束时报告实际检查、已核验修改和剩余项目。
