# 使用 agent-friend

## 对话与会话

- 在对话页输入内容并发送；生成过程中可以停止当前回复。
- 新对话会使用当前选择的模型和最新已应用的人格。
- 历史会话可继续、重命名、归档或删除；归档会话可在“设置 → 已归档对话”中恢复。
- 全局搜索用于查找不同会话中的内容，并可跳转到命中的会话位置。
- 删除与“清空全部归档”是永久操作，确认前先检查目标范围。

## 模型与附件

- 在对话输入区选择模型。设置页中的默认模型用于新对话；已有会话可以保留自己的模型选择。
- 只有当前模型声明支持附件时，输入区才允许添加图片或文档。
- 支持的文件类型、单文件大小、总大小和单轮数量由当前模型决定；以添加文件时的界面提示为准。
- 切换到不兼容的模型后，先移除不兼容附件或换回支持它们的模型再发送。

## 人格

1. 打开“设置 → 人格”。
2. 用自然语言描述希望修改的性格、表达方式或相处习惯。
3. 查看候选结果与变更差异。
4. 确认后应用；不满意可以继续讨论、撤销最近变更或重置。

人格变更从后续新一轮交流开始生效，不会重写历史消息。

## 桌宠

- 在“设置 → 桌宠”选择角色模型并调整显示比例。
- 常规比例和迷你状态比例可分别设置。
- 支持导入符合界面要求的 Spine 3.8 模型文件夹；导入前保留原始模型备份。

## 语音

- 点击输入区的麦克风开始语音输入，识别结果会写入当前草稿，仍可编辑后再发送。
- 语音通话是独立的连续通话能力，首次使用会说明麦克风与公网连接需求。
- 只在用户主动使用语音功能时申请或使用麦克风权限。
- 配置方法见 `voice-credentials.md`。

## Skill

- 在 Skill 管理入口查看内置、个人和项目 Skill。
- 安装第三方 Skill 前先确认来源可信；Skill 可能包含会影响 agent 行为的说明或脚本。
- Skill 是否可用与是否已经启用是两件事，按管理界面的状态和提示处理。

## 后台在线

“设置 → 通用”可选择跟随系统、仅接通电源或始终保持后台在线。该设置只在 agent 执行任务或 QQ 在线等需要持续运行的状态下阻止系统空闲睡眠；不会阻止显示器关闭，也不能覆盖合盖或系统强制睡眠。
