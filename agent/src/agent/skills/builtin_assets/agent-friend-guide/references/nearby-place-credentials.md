# 附近地点凭据

附近地点与地图查询使用高德开放平台的 **Web 服务 Key**。它是可选增强。

## 申请 Web 服务 Key

1. 登录 [高德开放平台控制台](https://console.amap.com/)。
2. 创建一个应用，或进入已有应用。
3. 在应用中添加 Key。
4. 服务平台必须选择 **Web 服务**；其他平台类型的 Key 不能替代。
5. 在 agent-friend 打开“设置 → 模型与凭据 → 地图与地点 / 高德”，粘贴并保存。
6. 等待对话服务自动应用，再尝试查询附近地点；任务占用服务时，结束任务后点击“重试应用”。

官方说明：[获取 Web 服务 Key](https://lbs.amap.com/api/webservice/guide/create-project/get-key)。配额、认证和计费规则以高德控制台为准。
