# 常见排查

## 重复启动或提示已有实例

- agent-friend 默认只运行一个正式桌面实例。再次从快捷方式、安装目录或另一份程序副本启动时，通常会唤醒已经运行的窗口，不会再开启一套后台服务。
- 如果提示已有另一类 agent-friend 实例正在运行，本次启动会停止，避免两套程序同时读写数据或争用服务。请回到原实例，从系统托盘正常退出后再重试。
- 不要为了继续启动而结束不认识的进程、删除应用数据或手工修改实例状态文件。无法确认原实例时，先在原窗口的“设置 → 帮助与反馈”生成诊断包；原窗口打不开时，保留提示截图并交给开发者排查。

## 安装程序无法继续

- 如果安装程序提示“安装前检查未通过”，agent-friend 尚未写入或替换程序文件；即使电脑从未安装过 agent-friend，也可能出现这类检查失败。
- 提示框会给出安装器诊断日志的位置，通常是当前 Windows 用户临时目录中的 `agent-friend-installer-<构建编号>.log`。不需要先成功安装或进入设置页，就可以提供这个文件。
- 如果失败前后出现 Windows 安全中心或第三方安全软件提醒，请检查“保护历史记录”或隔离记录。安全软件可能阻止安装器运行临时检查程序，这通常不是网络防火墙连接失败。
- 只有确认安装包来自可信来源，并与提供方公布的文件名及 SHA-256 校验值一致时，才恢复或允许被拦截的项目后重新运行安装器。不要为安装 agent-friend 整体关闭防火墙或杀毒保护。
- 如果仍然失败，请保留完整提示截图和诊断日志并交给开发者；不要自行删除应用数据，也不要查找或结束不认识的系统进程。
- 如果提示明确说无法创建诊断文件，只提供完整截图，并同时说明安装包文件名和选择的安装目录。

## 保存凭据后仍提示缺失

1. 检查字段是否填在正确能力下，例如天气需要 Key 和 Host，语音输入与通话需要不同组合。
2. 按保存后的提示重启对话服务或语音服务。
3. 如果设置页显示值来自系统环境或旧配置，那个来源可能覆盖设置页保存的新值；移除旧来源后再重启。
4. 不要在聊天中发送 Key 来排查。可在供应商控制台创建一枚新的独立 Key 替换测试。

## 模型请求失败

- 设置页显示“已配置”只表示 Key 已保存，不代表供应商已经验证它可用。保存或更换 Key 后，应选择对应模型发起一次普通对话确认。
- 401 或鉴权失败：Key 错误、已撤销或来自不兼容的平台。
- 如果刚更换 Key 后立即出现“请求格式或参数错误”，也应先回到供应商控制台确认 Key 可用并重新复制，避免错误提示掩盖鉴权失败。
- 余额或额度错误：到供应商控制台检查用量、余额和服务状态。
- 请求过多或服务繁忙：稍后重试；持续出现时查看供应商状态。
- 只有某一供应商失败：切换另一已配置模型，区分账号问题与本地通用问题。

## 附件不能添加或发送

- 当前模型可能不支持附件。
- 文件类型、单文件大小、总大小或单轮数量可能超出模型限制。
- 切换模型后已有附件可能不兼容；移除附件或换回兼容模型。

## 搜索、地点或天气不可用

- 联网搜索检查 Tavily Key。
- 附近地点检查高德 Key 是否为 Web 服务类型。
- 天气检查和风 API Key 与账号专属 API Host 是否同时填写，Host 不带协议和路径。
- 保存后重启对话服务。

## 语音不可用

- 先在“设置 → 系统权限”确认麦克风权限。
- 语音输入可用新版 APP Key，或旧版 APP ID + Access Token。
- 语音通话需要 AK、SK、RTC AppID、RTC AppKey、语音 APP ID、语音 Access Token 全部就绪。
- 确认火山相关服务已开通且可用，再重启语音服务。

## 本地命令或 Skill 脚本无法运行

- 如果命令卡片提示 Windows 沙箱尚未初始化，点击初始化操作并确认系统管理员提示；普通命令不会自行弹出管理员授权。
- 如果没有出现授权卡片，确认当前操作来自桌面聊天。不能展示授权的入口不会启动本地命令。
- 授权前检查命令、目录、文件访问范围和联网权限。拒绝、授权超时或路径在批准后发生变化时，命令会按安全策略停止；不要要求 agent 绕过沙箱重试。
- Windows PowerShell 5.1 脚本在当前沙箱中可能无法启动。可用同等的 exe、cmd 或 bat 入口；确实需要 PowerShell 时，使用已安装且可用的 PowerShell 7（`pwsh.exe`）。
- 命令运行中失联、超时或取消后会显示明确终态。若进程长期没有结束，先取消当前任务，再从“设置 → 帮助与反馈”生成诊断包。

## Windows 息屏恢复后桌宠暂时消失或桌面变黑

- 息屏恢复后，agent-friend 可能暂时隐藏桌宠，等待显示器和缩放状态稳定；通常数秒后会自动恢复。
- 如果恢复画面检查没有通过，agent-friend 会让桌宠保持隐藏，避免遮住整个桌面。确认桌面正常后，可从系统托盘选择“显示/隐藏桌宠”重新显示。
- 如果整个桌面持续黑屏，先退出 agent-friend 恢复桌面。恢复后尽快在“设置 → 帮助与反馈”生成诊断包，并注明大致发生时间、显示器数量，以及其他浏览器或应用当时是否也有异常。无需提前开启取证；最近一次息屏恢复事故证据会随你主动生成的诊断包自动包含。
- 不要为了复现而反复强制息屏，也不要把关闭显卡加速、修改驱动或停用安全软件作为首选排查方法。

## 迁移或恢复失败

- 确认是 Windows 到 Windows。
- 确认迁移包与对应 12 词迁移码匹配，文件没有被修改。
- 确保磁盘空间足够，不要在恢复过程中退出应用。
- 恢复失败后检查“最近回滚备份”，不要先删除它。

## 需要进一步排查

在“设置 → 帮助与反馈”生成诊断包。只选择与问题相关的会话；附件原件和手动渲染截图默认不要包含。息屏恢复事故的最近一次渲染证据可能自动包含；ZIP 不会自动上传，发送前仍要手工检查私人内容。
