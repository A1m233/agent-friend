# 开始使用

## 第一次使用

打开 AF 时，如果还没有向导完成记录，会自动出现独立的“设置助理”。随时可以切走或关闭，桌宠和其他窗口照常使用。确认基础配置前关闭，下次启动还会出现。到达“这下可以开聊啦！”就已完成向导，之后日常可以在设置中调整模型、语音和人格。需要重看向导时，支持本机命令的版本可用下文的 `--af-setup open` 打开。看不到教程的较早版本，可以在“设置 → 模型与凭据”完成相同的基础配置。

1. 连接一个模型服务。选择 DeepSeek、Kimi 或自定义连接（BYOK）。没有 Key 时前往所选服务的官方控制台；用户在 AF 内输入，模型服务可能按使用量收费。自定义连接需要服务地址、协议和至少一个可用模型。申请入口和字段说明见[模型凭据](model-credentials.md)。
2. 选择默认对话模型。它决定以后新建对话时由哪个模型回复。首次有可用模型时，AF 会把它同时设为默认对话模型和记忆模型。可以直接确认，也可以分别改选。
3. 选择默认记忆模型。它负责整理长期记忆，可以沿用对话模型。如果只配了 Kimi 或自定义服务，两项用途都要选到已连接的模型。连接已保存但尚未应用时，在凭据或自定义连接编辑区域重试应用。
4. 两项都就绪后，可以关闭向导照常聊天，或点“继续”浏览个性化设置。个性化设置依次介绍自主陪伴与通知、人格和语音输入。可以原样继续，也可以直接关闭窗口，以后随时在设置中调整。[语音输入](voice-credentials.md)需要语音 APP Key 或语音 APP ID + Access Token。人格可以沿用默认 Echo，也可以对话调整并查看、应用候选。自主陪伴和通知可以稍后再选。详见[设置参考](settings-reference.md)。

### 让本机 Agent 协助

可以从欢迎页复制提示词，也可以让自己的 Agent 直接阅读本 Skill。只需要指导时，按以上步骤带用户操作。支持新手引导命令的桌面版本，还能用同一个 AF 桌面可执行文件执行下面的本机操作。使用当前安装的桌面应用路径；“open”会打开窗口，应用未运行时命令可以启动它。若老版本无此入口，继续按设置页操作。

| 桌面可执行文件后面的参数 | 作用 |
| --- | --- |
| `--af-setup status` | 获得 JSON，包括已配置模型的 `model`、名称、两项默认模型与 `chatReady`、`memoryReady`。这反映当前连接和模型目录；额度、网络、实际生成结果要在使用时确认。 |
| `--af-setup open` | 打开新手引导。可追加步骤 connect、chat、memory、voice、persona、companionship，例如 `--af-setup open connect`。缺少前置连接时会先回到相应步骤。 |
| `--af-setup select chat MODEL_ID` | 将用户选定的模型设为默认对话模型。把 MODEL_ID 换成 status 返回的精确 `model`。 |
| `--af-setup select memory MODEL_ID` | 设置默认记忆模型，同样使用 status 返回的模型标识。 |

Windows 安装版正在运行时，可从任务管理器的文件位置或 AF 的开始菜单快捷方式找到桌面程序。AF 自身和外部 Agent 均可使用获准的本机命令工具调用它。若当前 Agent 只能聊天，则直接引导用户在桌面操作。

例如，在 PowerShell 里将 AF 桌面程序的实际路径放入 `$afExe`，执行 `& $afExe --af-setup status | Out-String`。每次命令检查 JSON 的 `ok`；保存后再查一次状态。若提示服务尚未就绪，等 AF 启动完成再试。无可选模型时打开引导，由用户配置凭据，不通过命令或聊天传递 Key。
