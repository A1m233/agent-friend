# 产品概览

agent-friend 是一个常驻桌面的 AI 朋友。它把日常对话、长期记忆、可编辑人格和桌宠形态放在同一个桌面应用中，并允许用户按需接入模型、联网工具与语音服务。

## 核心能力

- **对话与会话**：创建多轮对话、查看历史会话、继续旧对话、搜索全部会话，以及归档不常用会话。
- **长期记忆**：在持续交流中保留对未来有帮助的信息，并区分稳定的个人身份资料与需要按相关性回忆的普通事实。记忆会参与后续回答，但不会改写已经存在的历史消息。
- **人格**：通过自然语言和 agent-friend 一起编辑人格，预览变更后再应用，也可以撤销或重置。
- **交流方式**：默认以沉浸式朋友身份交流；用户也可以关闭沉浸模式，让 Echo 在相关问题中坦诚说明 AI 身份和实际信息来源。
- **待办与提醒**：通过对话创建和管理待办、设置提醒，并可在一次请求中变更多个待办的状态。
- **桌宠**：在桌面显示角色模型，并调整模型、常规缩放和迷你状态缩放。
- **模型选择**：可在支持的模型供应商和模型间选择；不同模型的附件能力可能不同。
- **在线工具**：配置后可使用联网搜索、附近地点与天气等能力。未配置某项可选工具时，普通对话仍可使用。
- **附件**：支持的模型可读取图片或文档；文件类型、数量和大小以当前模型在界面中的提示为准。
- **语音**：语音输入可把说话内容写入输入框；语音通话提供连续的实时语音交互。两者的配置要求不同。
- **Skill**：可安装和管理 Skill，让 agent 获得特定领域知识或工作流程。
- **数据迁移与诊断**：可生成加密迁移包搬迁数据，也可在本机生成诊断包用于排查问题。

## 能力边界

- 模型、在线工具和语音服务由第三方提供，通常需要用户自己的账号、凭据和可用额度。
- 某个模型不支持附件时，切换模型前已添加的附件可能不再兼容，界面会给出提示。
- 长期记忆用于帮助后续交流，不等于对每句话逐字永久保存或保证每次都能召回。
- 首版数据迁移只支持 Windows 到 Windows，目标电脑上的现有数据会整体替换，不自动合并。
