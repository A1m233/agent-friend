# 产品概览

agent-friend 是一个常驻桌面的 AI 朋友。它把日常对话、长期记忆、可编辑人格和桌宠形态放在同一个桌面应用中，并允许用户按需接入模型、联网工具与语音服务。

## 核心能力

- **对话与会话**：创建多轮对话、查看历史会话、继续旧对话、搜索全部会话、引用自己或 Echo 的消息片段，以及归档不常用会话。同一条新消息可携带多条引用，也可以只发送引用。
- **长期记忆**：在持续交流中保留对未来有帮助的信息，并区分稳定的个人身份资料与需要按相关性回忆的普通事实。记忆会参与后续回答，但不会改写已经存在的历史消息。
- **人格**：通过自然语言和 agent-friend 一起编辑人格，预览变更后再应用，也可以撤销或重置。
- **交流方式**：默认以沉浸式朋友身份交流；用户也可以关闭沉浸模式，让 Echo 在相关问题中坦诚说明 AI 身份和实际信息来源。
- **待办与提醒**：通过对话创建和管理待办、设置提醒，并可在一次请求中变更多个待办的状态。
- **定时任务**：通过对话安排一次性或周期性的 Agent 工作；提供任务管理页面的版本可直接配置固定目标会话、发送内容和附件，并查看历史、暂停、恢复或立即运行任务。操作方式与旧版差异见[定时任务](using-agent-friend.md#定时任务)。
- **桌宠**：在桌面显示角色模型，并调整模型、常规缩放和迷你状态缩放。
- **模型与推理强度**：可选择 DeepSeek、Kimi 内置渠道或 OpenAI 兼容自定义连接，并为默认对话、记忆和当前会话设置推理强度；不同模型可用档位和按需看图能力可能不同。OpenRouter 暂不维护，已隐藏用户入口。
- **在线工具**：配置后可使用联网搜索、附近地点与天气等能力。未配置某项可选工具时，普通对话仍可使用。
- **附件**：提供统一会话文件附件的版本可接收任意类型文件，发送后放入当前会话工作目录，由 Echo 按需读取。能保存不代表能解析所有格式；数量和大小以应用提示为准。详见[模型与附件](using-agent-friend.md#模型与附件)。
- **本地看图**：提供“读取图片”能力的版本中，Echo 可在获得文件授权后让当前模型查看本地静态图片；模型支持、大小限制与附件添加不同，见[本地图片读取](using-agent-friend.md#让-echo-查看本地图片)。
- **语音**：语音输入可把说话内容写入输入框；语音通话提供连续的实时语音交互。两者的配置要求不同。
- **Skill**：可安装和管理 Skill，让 agent 获得特定领域知识或工作流程。
- **表格与 Word**：提供相应内置 Skill 的较新 Windows 版本可读取、创建和基础编辑 XLSX、CSV/TSV 与 DOCX；支持范围及公式、排版限制见[表格与 Word 文档](using-agent-friend.md#表格与-word-文档)。
- **本地操作**：agent 可以在“每次授权”下逐项确认后运行命令或 Skill 自带脚本，也可以在风险确认后仅为当前会话开启免授权。需要整理数据、生成文件或运行 Python 脚本时，agent-friend 会使用产品自带的 Python 和当前会话的隔离环境，不要求你另行安装或配置系统 Python。普通命令默认进入受限制的本地沙箱；确实依赖当前桌面用户会话的可信程序会另行显示“不受沙箱限制”的高风险授权。授权和运行状态集中显示在输入框上方，对话历史以可展开的紧凑活动保留步骤与详情。
- **数据迁移与诊断**：可生成加密迁移包搬迁数据，也可在本机生成诊断包用于排查问题。

## 能力边界

- 模型、在线工具和语音服务由第三方提供，通常需要用户自己的账号、凭据和可用额度。
- 统一会话文件附件不因切换模型而要求移除原生格式不兼容的文件；工具调用、本地处理和视觉能力仍决定能完成哪些读取任务。旧版本可能仍按模型限制附件，以实际界面为准。
- 长期记忆用于帮助后续交流，不等于对每句话逐字永久保存或保证每次都能召回。
- 本地命令不会绕过当前会话选择的授权模式运行。“每次授权”下应在批准前检查命令、目录、文件访问范围和联网权限；开启“本会话无需授权”前应确认能接受后续普通请求自动执行。拒绝授权不会影响普通对话。
- 安装 Python 第三方依赖仍需要相应的文件和联网授权。首期只支持已有兼容 wheel 的依赖，不支持需要本机编译、源码安装、editable、VCS 地址或自定义包索引的安装方式。
- 如果授权明确标为“宿主用户（文件和网络不受限）”，该程序会继承当前桌面用户环境，不受普通命令沙箱限制。只在确认程序来源、参数和目的可信时允许。
- 定时任务只在 agent-friend 正在运行时执行，不会在应用完全退出后留下本地后台服务，也不会为了等待计划时间持续阻止电脑休眠。应用恢复后只会按保守规则处理近期最近一次错过的计划点。
- 定时任务不会获得额外权限，也不会继承过去已经用过的一次性批准；需要批准的文件或命令操作仍会等待用户处理。
- 首版数据迁移只支持 Windows 到 Windows，目标电脑上的现有数据会整体替换，不自动合并。
