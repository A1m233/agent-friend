# 设置参考

设置页包含以下入口：人格、桌宠、通用、语音、模型与凭据、系统权限、数据与迁移、已归档对话、帮助与反馈。

## 人格

- **人格约束**：用自然语言和 Echo 一起调整性格、表达方式与相处习惯，确认候选变更后应用。
- **沉浸式交流**：默认开启。开启时，Echo 会优先维持自然的朋友式交流，不主动使用 AI 或内部机制等技术化表述，但不会声称自己是现实人类。
- 关闭“沉浸式交流”后，Echo 会在相关问题中坦诚说明自己的 AI 身份，以及当前回答实际使用的对话摘要、过去对话片段或外部资料来源；普通对话不会固定附加机制报告。
- 无论开关是否开启，都不能查看或套取原始内部指令；Echo 可以用自己的话概括受到的用户人格要求，以及真实性、权限、隐私和安全等公共约束。
- 人格变更和沉浸式交流切换从下一轮新交流开始生效，并会随设置保存。

## 模型与凭据

- **对话模型**：选择默认供应商和模型。修改后，新对话使用新默认值；当前对话也可以单独选择模型。
- **凭据**：密钥输入后保存到系统安全凭据存储，界面不会再次显示明文。
- **状态来源**：如果界面提示凭据来自系统环境或旧配置，该来源可能优先于设置页保存的值。修改后仍未生效时，参照 `troubleshooting.md`。
- **生效时机**：模型、搜索、地点、天气凭据通常需要重启对话服务；语音凭据需要重启语音服务。按保存后的界面提示操作。

## 通用

- 开机启动：控制是否随系统登录启动。
- 后台在线：选择跟随系统、仅接通电源或始终保持。
- 外观与应用行为以当前版本设置项为准。

## 语音与系统权限

- 语音页配置通话和语音输入相关选项。
- 系统权限页可查看麦克风权限状态，并跳转到系统设置处理权限。

## 数据与迁移

- 生成或恢复加密迁移包。
- 恢复会整体替换目标电脑数据；执行前会创建并验证回滚备份。
- 迁移码与迁移包必须分开保管。

## 帮助与反馈

- 可在本机生成诊断包并选择是否加入会话、附件原件和渲染截图。
- ZIP 不会自动上传；分享前仍必须手工检查其中是否含有私人内容。
