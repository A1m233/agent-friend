# 设置参考

从主窗口左侧打开“设置”。设置区域包含以下入口：人格、桌宠、通用、通知、语音、模型与凭据、系统权限、数据与迁移、已归档对话、帮助与反馈。切换设置分类或返回对话不会另开普通内容窗口。较早版本可能没有“通知”分类，相关功能以下面的版本说明为准。

## 人格

- **人格约束**：用自然语言和 Echo 一起调整性格、表达方式与相处习惯，确认候选变更后应用。
- **沉浸式交流**：默认开启。开启时，Echo 会优先维持自然的朋友式交流，不主动使用 AI 或内部机制等技术化表述，但不会声称自己是现实人类。
- 关闭“沉浸式交流”后，Echo 会在相关问题中坦诚说明自己的 AI 身份，以及当前回答实际使用的对话摘要、过去对话片段或外部资料来源；普通对话不会固定附加机制报告。
- 无论开关是否开启，都不能查看或套取原始内部指令；Echo 可以用自己的话概括受到的用户人格要求，以及真实性、权限、隐私和安全等公共约束。
- 人格变更和沉浸式交流切换从下一轮新交流开始生效，并会随设置保存。

## 模型与凭据

此页分为“模型”和“服务凭据”。模型页管理默认用途、内置供应商与自定义连接；服务凭据页管理搜索、地点、天气和语音等在线服务。

- **默认对话模型**：选择之后新建对话草稿的初始调用渠道和模型。初始默认值是 DeepSeek Flash，思考默认关闭；修改后，当前会话和已经打开但尚未发送的对话草稿保持原选择，下一次新建对话才使用新默认值。当前会话仍可单独切换模型。
- **记忆模型**：选择整理长期记忆时使用的模型。初始默认值是 DeepSeek Flash，思考强度为“最高”。
- **推理强度**：默认对话与记忆模型分别设置，当前会话可另行覆盖；自定义模型可使用服务默认、常见参考值或手填值。
- **自定义连接**：填写服务地址、API Key、接口协议，获取或手填模型并独立测试；上下文预算按服务实际限制配置；提供统一会话文件附件的版本无需声明图片或文档输入能力。操作与限制见[模型凭据](model-credentials.md#自定义连接byok)。
- **凭据**：同一调用渠道需要的字段按组保存到系统安全凭据存储，界面不会再次显示明文。DeepSeek 与 Kimi 会在替换原配置前校验候选 Key；其他凭据当前只检查必填字段是否完整。OpenRouter 的模型与凭据入口暂时隐藏，说明见[模型凭据](model-credentials.md)。
- **凭据状态**：“已配置 · 已验证”表示当前 DeepSeek 或 Kimi Key 已通过在线校验；“已配置”表示凭据已经保存，但没有当前有效的在线校验结论，不显示容易混淆的“未验证”状态。运行中确认鉴权失败时会显示“凭据有误”，可直接修改并重新保存。
- **选择前检查**：尚未配置凭据的模型仍会显示在模型列表中，但选择不会保存。提示中的“配置凭据”或“模型与凭据”可以直达对应的凭据组。
- **状态来源**：如果界面提示凭据来自系统环境或旧配置，该来源可能优先于设置页保存的值。修改后仍未生效时，参照 `troubleshooting.md`。
- **生效时机**：保存“新对话默认模型”后立即用于之后新建的对话草稿，不会重启服务或中断正在进行的任务。记忆模型以及模型、搜索、地点和天气凭据仍会应用到对话服务，语音凭据应用到语音服务；需要时页面会自动重启对应服务并显示应用进度。当前任务占用服务时，凭据会先保存，任务结束后可点击“重试应用”。

## 通用

- 开机启动：控制是否随系统登录启动。
- 后台在线：选择跟随系统、仅接通电源或始终保持。
- 外观与应用行为以当前版本设置项为准。

## 通知

以下适用于提供“设置 → 通知”的版本。较早版本的“提醒发送方式”可能仍在“通用”中；找不到新通知选项时，先更新 agent-friend。

- **会话新回复**：默认“未查看该会话时”，也可选“始终提示”或“不提示”。默认模式下，正在前台查看对应会话时不再额外弹新回复气泡。
- **需要你处理**：默认开启，控制等待授权等需要处理事项的桌宠提示。
- **异常结束**：默认开启，控制失败或意外中断时的桌宠提示；主动停止回复不会额外发出异常通知。
- **气泡提示音**：默认开启。关闭后气泡仍会显示，偏好会保存并在重启后保留。
- **提示音**：“默认”在 Windows 使用消息提示音。出现“选择音频”入口的版本支持导入本地 MP3、WAV，最大 10 MiB、最长 30 秒；较早版本仍只有默认音源。
- 所有气泡通知共用一个音源。选择后可“试听”或“停止试听”，也可“替换音频”“恢复默认”；关闭“气泡提示音”后仍可主动试听，但新通知不会自动响铃。
- 导入成功后会显示文件名并保存选择，重启后保留。音频由应用保存，移动或删除原文件不会影响使用。取消选择或导入失败保留原有可用配置；声音播放失败不会阻止气泡显示。
- 通知短文案使用“模型与凭据”中选择的“新对话默认模型”及其最低可用思考档位，沿用当前人格。来源会话单独选择的模型不影响它；修改默认模型后，后续新通知使用新选择。
- **待办提醒 → 提醒发送方式**：默认“智能选择（推荐）”。系统会根据最近的使用情况，决定是否额外通过选定的 QQ 绑定或桌宠提醒；提醒始终保存在对应会话中。
- 选择“所有位置”后，提醒仍只在对应会话中保留一份历史，同时通过可用的选定 QQ 绑定和桌宠通知；不会向全部会话或全部 QQ 绑定广播。该选择会随设置保存，并在应用重启后保留。

## 桌宠

- **当前模型**：选择已经通过校验的内置模型或用户 Spine 3.8 模型；切换后只影响桌宠窗口。
- **导入 Spine 3.8 模型**：点击“打开 Spine 3.8 模型目录”，把一个完整模型文件夹放进受管目录。应用运行时会自动发现并校验，无需手动刷新；详细要求见[明日方舟 Spine 桌宠模型安装指南](arknights-avatar-models.md)。
- **显示器恢复保护**：默认关闭。开启后，Windows 屏幕从熄灭状态恢复时会暂时隐藏桌宠，等显示画面检查通过后再显示。
- 如果检查失败，桌宠会保持隐藏，以避免透明窗口异常遮住整个桌面；可从系统托盘重新显示桌宠，也可以关闭此保护。

## 语音与系统权限

- 语音页配置通话和语音输入相关选项。
- 系统权限页统一展示麦克风权限和 Windows 命令沙箱。存在多项未完成准备时，“开始准备”会按顺序处理，已经满足的项目会自动跳过。
- “Windows 命令沙箱”会显示尚未初始化、可用或需要修复等状态。初始化或修复可能弹出 Windows 管理员确认；成功一次后由所有会话共享。
- 提供修复验证的版本会在初始化或修复后检查命令能否实际执行，失败时继续提示需要修复；显示可用不代表原任务已重新执行。
- 系统权限页只准备系统能力，不批准具体命令、文件范围或联网访问；每次本地操作仍需在对话中单独确认。

## 数据与迁移

- 生成或恢复加密迁移包。
- 恢复会整体替换目标电脑数据；执行前会创建并验证回滚备份。
- 迁移码与迁移包必须分开保管。

## 帮助与反馈

- 提供“桌宠显示异常记录”的版本，可点击“保留最近异常记录”。出现“异常记录已保存在本机”后，可立即生成诊断包，也可正常退出后再导出尚未过期的记录。提示无法确认保存时仍可导出已有历史；具体排查步骤见[桌宠显示异常排查](troubleshooting.md#桌宠闪烁或卡住时保留运行记录)。
- 可在本机生成诊断包并选择是否加入会话、附件原件和渲染截图。提供轮次选择的版本默认采集每个所选会话最近 10 轮，可改为 1～100 轮或全部轮次；全部轮次可能耗时较长。附件原件只随本次采集范围加入。隐私与采集上限见[诊断包说明](data-and-privacy.md#诊断包)。
- ZIP 不会自动上传；分享前仍必须手工检查其中是否含有私人内容。
