# 安装明日方舟 Spine 桌宠模型

agent-friend 可以从 [Ark-Models](https://github.com/isHarryh/Ark-Models) 选择一个干员或时装的基建小人模型，下载到本机受管理的 Spine 3.8 模型目录。这里安装的是用户本地模型，不会把素材变成 agent-friend 的内置资源，也不会自动切换当前桌宠。

## 使用边界

- 只处理 Ark-Models `models/` 下的干员基建小人。敌人战斗模型和动态立绘不属于这个流程。
- Ark-Models 声明素材版权归上海鹰角网络有限公司所有，不得用于商业用途，也不得损害版权方利益。安装前必须让用户确认仅作本地非商用使用；不要把模型重新上传、打包分发或描述成可自由使用的素材。
- 不下载整个 Ark-Models 仓库。仓库体积较大，只取得用户选中的一个模型目录。
- 只支持 Spine 3.8 二进制模型：同名 `.skel`、`.atlas` 和 atlas 引用的全部贴图。Spine 4.x、Spine 3.8.75、JSON skeleton、Live2D、ZIP 包都不在本流程内。
- 用户只想了解步骤时，不运行脚本。实际搜索需要联网授权；实际安装还需要对目标模型目录的写入授权。

## 选择模型

用户可以说中文名、英文名、Ark-Models 目录名，或同时说明时装名称。优先运行 Skill 包内脚本搜索，不凭记忆猜目录：

```text
scripts/ark-models.py search --query "<角色或时装>" --ref main
```

搜索结果会返回 `resolvedCommit` 和候选列表。候选不唯一时，列出名称、时装、目录标识和类型，让用户选择；不要把默认服装、时装或异格自动视为同一个模型。选定后，后续安装必须使用搜索返回的精确 commit，而不是再次读取可能已经变化的 `main`。

## 安装前确认

1. 按[数据与隐私中的“本地数据位置”](data-and-privacy.md#本地数据位置)解析当前实例的用户 Spine 3.8 模型目录。Agent 应先从本机 `tauri.log` 的最新 `avatar models: assets_dir="..."` 记录取得实际模型资源根目录，再追加 `user/spine38`；能够自行解析时不要让用户复制路径。只有日志不可用或没有该记录时，才请用户前往“设置 → 桌宠 → 打开 Spine 3.8 模型目录”，从文件管理器地址栏复制完整路径。
2. 在执行前说明：模型名称与时装、Ark-Models 目录标识、精确来源 commit、将创建的目标文件夹，以及“只作本地非商用使用”的限制。
3. 用户明确同意后才运行安装。普通文件与联网授权仍由 agent-friend 的授权流程处理，Skill 本身不扩大权限。

## 执行安装

使用用户选定的目录标识、搜索得到的精确 commit 和受管目录：

```text
scripts/ark-models.py install --slug "<Ark-Models 目录标识>" --ref "<resolvedCommit>" --models-dir "<按 data-and-privacy.md 解析的用户 Spine 3.8 模型目录>" --acknowledge-noncommercial
```

需要先查看将创建什么而不写文件时，加 `--dry-run`；dry-run 不代表模型文件已经通过校验。脚本会：

- 从上游 metadata 核对目录、角色和时装；
- 只下载该模型的 skeleton、atlas 和贴图；
- 拒绝路径逃逸、缺失贴图、不兼容 Spine 版本和同名目标；
- 先在临时位置完成下载与校验，再把完整目录复制到受管目录；
- 在模型目录保存来源 commit、文件摘要和非商用提醒；
- 不覆盖已有目录，不修改其它用户模型，也不替用户选择当前桌宠。

完整的 40 位提交号会直接用于固定版本读取；分支、标签或短提交号仍先解析为完整提交号。提交或文件不存在时会报错，不会改为安装最新版。下载遇到超时、连接断开或读取中断时，每条下载路径最多尝试 3 次；原始文件地址仍失败时，只回退到同仓库、同提交的 GitHub 官方文件接口。该备选接口不支持超过 100 MB 的单个文件，原有文件与模型大小检查仍然生效。

来源记录中的 SHA-256 由本次下载内容计算，可用于复核落盘文件是否一致，不代表已经与上游独立公布的摘要核验。

脚本成功只表示资源已经安全复制。agent-friend 仍会用正式 Spine 3.8 runtime 校验模型；应用运行时通常会自动发现，无需刷新。应用没有运行时，下次启动会扫描。

## 安装后

1. 回到“设置 → 桌宠”。
2. 等待新模型出现在“当前模型”列表；名称来自安装目录，末尾保留 Ark-Models 目录标识以便追溯。
3. 选择模型并按需要调整“模型大小”和“缩小模式比例”。

保留 Ark-Models 标准动画名称的模型会自动复用与内置明日方舟桌宠相同的点击、拖拽和状态动画。某个约定动画不存在时，只有对应动作会安全回退到默认动画，不影响模型显示和其它可用动作。

如果模型没有出现，先看同页的导入诊断：

- 提示资源不完整：重新安装，不要只补单个散文件。
- 提示 Spine 版本不支持：该上游模型不能通过当前导入流程使用，不要绕过校验。
- 目标目录已存在：先确认它是否是用户已有模型；本流程不自动替换或删除。
- GitHub 限流：本次执行停止；若错误包含等待秒数或额度重置时间，等到指定时间后再试，不要连续重跑或换接口绕过限流。
- 网络失败：瞬时连接问题会有限重试并尝试官方备选路径；证书校验等非瞬时错误会直接停止。仍失败时保留错误信息、来源提交号和脚本版本，稍后再试。不要静默改用第三方代理源。
- 文件或提交不存在、响应内容异常、文件超过大小限制：本次执行停止，不绕过检查或自动换成其它版本。
