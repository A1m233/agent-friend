# 数据与隐私

## 本地数据位置

agent-friend 的会话、记忆、人格和其他用户资产默认保存在系统用户数据目录：

- Windows：`%APPDATA%/agent-friend/`
- macOS：`~/Library/Application Support/agent-friend/`
- Linux：`$XDG_DATA_HOME/agent-friend/`，未设置时通常是 `~/.local/share/agent-friend/`

Windows 日志默认位于 `%LOCALAPPDATA%/agent-friend/Logs/`。不要在应用运行时手工移动或修改数据文件；迁移电脑时使用设置页的迁移功能。

普通本地命令可以使用当前会话自己的受管命令目录。该目录会在同一会话的后续任务中保留；归档会话不会删除它，永久删除会话或清空对应归档会话时会一并删除。

Python 任务还会为当前会话保留独立的依赖环境。产品自带的 Python 基础环境和下载缓存可以由多个会话复用，但各会话不会共享可写的依赖目录。删除会话时会清理对应的会话环境；为减少重复下载而保留的共享缓存会按产品的磁盘治理规则统一清理。不要手工修改这些受管环境或把它们当作个人 Python 安装使用。

## 定时任务数据

- 定时任务的名称、指令、时间规则、状态和每次运行历史保存在本机用户数据中。每次实际执行还会形成一段独立对话，用于保留回复、工具步骤和最终结果。
- 这些独立运行默认不出现在普通历史会话列表中，但仍属于本地历史数据。删除定时任务只会停止未来执行，不会自动抹掉已经发生的运行事实或外部副作用。
- 任务开始执行时，保存的指令会发送给当时选择的模型；如果任务使用联网工具、第三方平台或本地命令，相应的数据处理与授权边界和普通对话一致。
- 应用完全退出后不会留下独立的定时任务后台服务。系统休眠期间也不会在本机执行任务；应用恢复后按近期错过规则处理。

## 凭据

- 在设置页保存的 API Key 会进入系统安全凭据存储，界面不会再次显示明文。
- 不要在普通对话中粘贴 Key，也不要把带 Key 的截图或配置文件公开。
- 怀疑泄露时，到对应供应商控制台撤销并重建。

## 模型附件

- 附件原件保存在本机用户数据中，是继续历史对话时的主要来源。切换模型或远端引用失效时，agent-friend 会根据本地原件重新处理。
- 使用 DeepSeek V4 Flash Vision 发送图片时，图片会上传到 DeepSeek，并设置约 24 小时后自动过期的远端副本，用于近期对话复用。删除本地附件不会立即删除已经上传的副本，但远端副本不会永久保留。
- 不要向任何第三方模型发送不希望其处理的敏感图片；发送前先确认当前选择的模型和调用渠道。

## 数据迁移

- 迁移包是加密文件，可包含会话、记忆、人格、设置、系统凭据、QQ 绑定和用户模型。
- 12 词迁移码不会写入迁移包，必须与文件分开保存；丢失后无法恢复该迁移包。
- 首版仅支持 Windows 到 Windows。
- 恢复会整体替换目标电脑的相关数据，不会合并。
- 替换前会创建并验证回滚备份；应用只保留最近一份，除非用户主动删除，不会按时间自动删除。

## 诊断包

- 诊断 ZIP 只保存到本机下载目录，不会自动上传。
- 选中的会话可能包含私人聊天内容以及工具参数和结果。
- 系统会过滤可识别的凭据，但不会替用户删除所有普通隐私信息。
- 诊断包会包含桌面实例治理摘要，用于判断本次启动是新建、唤醒已有实例、被拒绝还是从异常残留中恢复。摘要不包含聊天正文或凭据，但可能包含进程编号、程序路径、安装目录或开发工作目录；这些路径可能带有系统用户名。
- 诊断包会记录受管执行环境的版本、内容身份、健康状态、会话环境数量和失败类别，帮助区分产品环境损坏、依赖失败与普通命令问题。该摘要不包含用户脚本正文、用户文件正文、包索引凭据或完整命令输出。
- 原始附件默认不包含；开启后可能加入私人图片和文档。
- 渲染证据可能包含完整桌面截图和桌宠内部截图，敏感程度很高。手动采集的截图需要你在生成诊断包时确认包含；显示器从息屏恢复或 Windows 渲染进程异常时自动保存的最近一次事故证据，会在你主动生成诊断包时自动包含，无需提前开启。

把诊断包交给任何人之前，按私人文件处理并逐项确认内容。无需分享的附件和手动截图不要勾选；如果刚发生过息屏恢复或渲染进程异常，还要留意诊断包可能自动包含该次完整桌面截图。

## 安装器诊断日志

- 安装程序在安装前检查失败时，会把诊断日志保存在当前 Windows 用户的临时目录，并在提示框中显示完整位置。
- 这份日志用于记录安装包版本、安装位置、失败阶段，以及临时检查程序的路径和执行后存在状态；不需要启动 agent-friend，也不包含会话、附件或设置页中保存的 API Key。
- 日志中的本机路径可能包含 Windows 用户名、安装包存放位置和自定义安装目录。发送给开发者前仍应按私人文件检查，不要公开发布。
- 问题排查结束后可以删除对应的 `agent-friend-installer-<构建编号>.log`；删除它不会影响已安装的 agent-friend 或用户数据。
