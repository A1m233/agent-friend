# client

`agent-friend` 的**客户端模块**——负责让 AI 朋友能够"操控电脑"（键鼠模拟、屏幕截图、系统级 API 调用等）。

## 状态

**孵化期不实现，仅占位预留。**

> 孵化期严格聚焦"对话 + 记忆"，操控电脑的能力等到桌宠形态稳定后再考虑。详见 [`docs/decisions/0002-incubation-tech-stack/README.md`](../docs/decisions/0002-incubation-tech-stack/README.md) 第 3.8 节。

## 未来语言与架构倾向

- **语言**：Rust（与 Tauri 内核栈一致，跨平台原生能力成熟）
- **架构**：独立进程（不与桌宠前端同进程，避免桌宠崩溃影响操控能力）

具体决策推迟到 **Phase 1 启动前**。

## 关键挑战（提前记录，避免被遗忘）

- macOS 的"辅助功能"和"屏幕录制"权限必须用户主动授权
- 能力清单的"滑坡问题"——键鼠 / 截图 / 剪贴板 / 文件 / shell 命令，越往后权限越大
- 是否对每次 AI 调用做二次确认？

详见 0002 第 3.8 节与待评估清单（第 4 节）。
