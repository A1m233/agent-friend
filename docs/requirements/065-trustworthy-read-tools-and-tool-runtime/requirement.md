# 065 · 可信读取工具与可扩展工具运行时

> Trustworthy Read Tools & Extensible Tool Runtime

## 状态

CONFIRMED

## 1. 背景

agent-friend 已具备通用工具调用机制、互联网搜索和历史对话召回，但工具覆盖仍不足，模型在以下任务中只能依赖心算、已有知识或不合适的搜索能力：

- 精确数学、百分比和统计计算；
- 日期差、时间加减、星期、闰年和时区换算；
- 读取用户指定网页、搜索结果页面或 PDF 的正文。

这些缺口已经造成过真实错误。数学和日期时间答案一旦算错，会直接损害用户对 Echo 的信任；只有搜索摘要而不能读取原始页面，也会让指定网页、官方文档和 PDF 场景缺少完整证据链。

现有工具循环还以固定的 5 次工具续轮作为主要保护。它能防止简单死循环，但也会限制“搜索 → 阅读多个来源 → 继续核验 → 汇总”之类合理的长链路。更重要的是，agent-friend 未来可能从即时陪伴对话继续演化出长时间分析或自治任务，基础运行时不能预设产品永远只执行短任务。

本需求同时补齐三项可信读取工具，并把任务长度从单一固定轮数升级为按执行场景配置的预算策略。

## 2. 目标

- 为需要确定性答案的计算和日期时间问题提供可靠工具，不再让模型心算关键结果。
- 让 Echo 能读取指定网页和文本型 PDF 的正文，以原始来源补全搜索证据链。
- 让合理的多步工具链可以继续执行，不再被写死的 5 次续轮提前截断。
- 保留防失控能力，并让短交互、长分析和未来后台任务可以采用不同的运行预算。
- 保持工具调用过程可取消、可诊断、可追溯，并在预算耗尽时诚实收尾。

## 3. 范围

### 3.1 精确计算 `calculate`

- 支持基础算术，包括加、减、乘、除、乘方、括号和正负数。
- 支持常见百分比问题，包括占比、增长率、折扣和百分数增减。
- 支持基础统计，包括求和、数量、平均数、中位数、最小值和最大值。
- 对能够精确表示的输入给出稳定、可复现的结果；不使用模型生成的近似心算替代工具结果。
- 对除零、非法表达式、非有限数值、超出支持范围等输入返回明确失败，模型不能据此编造结果。
- 工具只执行受支持的数学运算，不具备运行任意代码或访问本地环境的能力。

### 3.2 日期时间计算 `datetime_calculate`

- 支持两个日期或时间之间的差值计算。
- 支持按天、周、月、年、小时、分钟等常见粒度进行时间加减。
- 支持查询指定日期是星期几、某年是否为闰年。
- 支持不同时区之间的时间换算，并正确处理跨日、跨月和跨年。
- 当问题包含“今天”“明天”“下周”等相对时间时，以本轮可信运行时日期和时区为基准。
- 输入缺少决定结果所必需的日期、时间或时区且无法从当前上下文可靠获得时，要求用户澄清，不能静默猜测。
- 结果需要包含足以消除歧义的绝对日期、时间和时区信息。

### 3.3 网页正文读取 `web_fetch`

- 能读取用户明确提供的 URL。
- 能读取本轮 `web_search` 实际返回的 URL，形成“搜索 → 阅读原文 → 回答”的证据链。
- 不允许模型凭空构造未由用户提供、也未由本轮搜索得到的任意 URL 作为读取目标。
- 支持普通网页正文提取，返回来源 URL 和适合模型阅读的主体内容。
- 支持包含文本层的 PDF；扫描件、图片型 PDF 的 OCR 不在本期范围。
- 支持按问题聚焦读取，避免无差别把超长页面全文全部塞入模型上下文。
- 页面读取失败、内容为空、格式不支持、访问受限或超时时返回可区分的失败结果，模型不能假装已经读到原文。
- 网页和 PDF 内容一律视为外部不可信数据；其中出现的指令不能覆盖 system prompt、工具契约或用户意图。

### 3.4 可扩展的工具运行预算

- 工具循环的任务长度不再由写死的 5 次续轮决定。
- 运行预算至少能够分别表达：模型工具续轮数量、工具调用总数和整轮执行时长。
- 不同执行场景可以采用不同预算；任一维度可以按场景设置合理上限，也允许在显式策略下不设置该维度的上限。
- 预算是运行策略，不是产品定位。核心循环不得假设所有任务都是短对话，也不得假设所有任务都应无限执行。
- 配置了预算时，接近边界应向模型提供剩余预算信号，让模型优先完成关键取证并主动收敛，而不是毫无预警地撞上硬边界。
- 到达硬边界后停止继续调用工具，基于已有证据完成回复；证据不足时明确说明未完成的部分，不得伪装为完整结论。
- 预算触发原因、实际模型续轮数、工具调用总数和最终停止原因可被诊断。

### 3.5 始终生效的安全边界

无论某个执行场景是否限制总轮数或总时长，以下边界始终生效：

- 用户取消或上游中断能够终止后续工作。
- 单个工具调用具有超时或等价的有界等待能力，不能永久阻塞整轮执行。
- 连续出现相同工具、相同参数和相同失败结果时能够识别无进展循环并停止重复消耗。
- 工具结果进入模型前继续服从上下文预算和安全投影；原始会话事件的可追溯性不被破坏。
- 同一模型响应中的独立只读工具可以安全并行；结果与事件仍能和原始 tool call 正确对应。
- 工具异常不会让会话无记录地中断，用户得到符合现有人设与工具契约的自然说明。

## 4. 不包含

- 符号代数、方程求解、微积分、数学证明和绘图。
- 通用单位换算、货币汇率和需要实时市场数据的金融计算。
- 执行任意 Python、JavaScript、shell 或用户提供的程序代码。
- 整站爬取、递归跟随网站链接、登录态页面、验证码处理或绕过访问控制。
- 扫描版 PDF、图片文字识别和复杂版面视觉理解。
- 记忆查看、记忆纠正或遗忘；由平级需求单独处理。
- 提醒创建与管理；由平级需求单独处理。
- 地点、附近 POI、路线或地图能力；由 `nearby-place-search` 平级需求单独处理。
- MCP、第三方动态工具市场或用户工具配置 UI。
- 后台任务的暂停恢复、阶段进度 UI、完成通知和跨重启任务调度。本需求只保证工具循环的预算策略不预先阻塞这些演进方向。

## 5. 用户体验与信任边界

- Echo 可以自然表达“我算一下”“我看看原文”，但只有实际调用对应工具后才能声称完成了该动作。
- 工具结果是证据，不是必须原样展示给用户的技术输出；最终回答应保持当前 persona 的自然表达。
- 当用户追问依据时，网页读取结果能够提供实际来源 URL；计算和日期时间结果能够说明关键输入和结论。
- 工具失败、预算耗尽或用户中断时，不暴露 provider、schema、调用栈等内部细节，也不捏造已经完成的动作。
- 长任务被允许持续运行，不等于可以失去用户控制；用户始终可以中断当前执行。

## 6. 验收标准

### 6.1 精确计算

- [x] `calculate` 能正确处理带括号和小数的基础算术。
- [x] `calculate` 能正确处理占比、增长率、折扣和百分数增减案例。
- [x] `calculate` 能正确返回 sum、count、mean、median、min、max 等基础统计结果。
- [x] 除零、非法表达式、非有限数值和不支持的数学能力返回失败，不执行任意代码。
- [x] 模型在明确需要精确计算的问题中使用工具结果，不用冲突的心算结果覆盖它。

### 6.2 日期时间

- [x] `datetime_calculate` 能正确计算日期差和时间加减，覆盖跨月、跨年与闰年边界。
- [x] 能正确返回星期与闰年判断。
- [x] 能完成至少两个不同时区之间的换算，并正确处理跨日结果。
- [x] 相对日期使用本轮可信日期和时区；必要输入缺失时要求澄清。
- [x] 最终结果包含消除歧义所需的绝对日期、时间和时区。

### 6.3 网页与 PDF

- [x] 用户提供普通网页 URL 后，`web_fetch` 能返回主体内容和来源 URL。
- [x] `web_search` 返回结果后，模型能继续读取其中指定页面并依据原文回答。
- [x] 包含文本层的 PDF 能提取出可用于回答的正文；扫描版 PDF 明确返回当前能力边界。
- [x] 模型尝试读取既非用户提供、也非本轮搜索结果的 URL 时，工具拒绝执行。
- [x] 超长内容被有界聚焦或裁剪，不导致模型上下文失控；页面内指令不能改变工具或系统行为。
- [x] 页面失败、内容为空、超时或格式不支持时，模型不声称已经读到原文。

### 6.4 工具运行时

- [x] 自动化测试证明合理任务可以执行超过现有 5 次工具续轮，并正常完成。
- [x] 至少两种不同运行预算可以在不改核心循环代码的前提下生效，且任务长度表现不同。
- [x] 显式允许某一预算维度不设上限时，该维度不会被隐含的固定 5 轮规则截断。
- [x] 接近已配置预算时，模型能收到剩余预算信号并有机会主动收敛。
- [x] 到达硬边界后不再执行新工具，最终事件能区分正常完成与预算耗尽。
- [x] 单工具超时、用户取消和重复失败循环均有自动化覆盖。
- [x] 同一模型响应中的多个独立只读工具可以安全并行，tool call/result 配对和持久化顺序保持正确。
- [x] 诊断信息能看到停止原因、模型续轮数和工具调用总数，且不记录网页正文、用户隐私或敏感凭据。

### 6.5 回归与门禁

- [x] 现有 `web_search`、`recall_past_chats` 和工具调用事件投影行为不退化。
- [x] 工具循环续轮、上限收尾、编辑重发、并发 session、上下文压缩和取消相关测试继续通过。
- [x] 默认自动化测试不触发真实 LLM、Tavily 或其他付费外部 API。
- [x] 项目统一检查脚本全部通过。

## 7. 待技术方案确认

- 计算输入采用表达式、结构化操作还是混合形式，以及精度和数值规模边界。
- 日期时间工具如何表达自然月/自然年与固定时长，如何处理夏令时和不存在/重复的本地时间。
- 网页正文读取优先复用现有 provider 还是增加本地 fallback；PDF 的可靠提取路径与安全限制。
- URL 来源证明如何随本轮执行传递，避免依赖不可验证的 prompt 约定。
- 运行预算的策略接口、默认策略、剩余预算提示时机和显式无上限配置。
- 单工具超时如何与现有同步 Tool Protocol、用户取消和工具 hook 协同。
- 哪些只读工具可并行，以及如何保持事件顺序、错误隔离和 provider 线程安全。
- 重复失败循环的签名、阈值和误判保护。
