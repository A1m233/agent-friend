# 178 当前会话内查找

## 状态

CONFIRMED

## 背景与目标

用户在阅读长会话时，需要回到之前说过的一句话。当前对话页将单按 `Ctrl+F` 留给 WebView，用户观察到查找栏出现在聊天窗口外。页面查找也无法覆盖尚未加载的历史消息。用户希望在会话面板内输入关键词，直接读到每一处匹配的上下文。

## 范围

- 当前会话的用户消息、助手回复，以及用户可以展开阅读的助手过程文字都属于可查找正文。折叠状态不影响匹配数量。
- 查找范围排除其他会话、侧栏、输入草稿、工具参数、原始工具输出、附件内容及未向用户展示的内部事件。
- 会话内查找和已有的[全局对话搜索](../074-global-conversation-search/requirement.md)分别使用独立快捷键。

## 验收条件

- [x] 在对话页按 `Ctrl+F`（macOS 为 `⌘F`），当前会话面板右上角出现查找栏并聚焦输入框。拖动、缩放或最大化桌面窗口时，查找栏始终位于面板内，也不会同时弹出原生页面查找栏。
- [x] 当关键词只出现在其他会话、侧栏或输入草稿时，当前会话显示零处匹配。全局搜索仍可通过 `Ctrl+Shift+F`（macOS 为 `⌘⇧F`）打开。
- [x] 长会话中仅在未加载的历史正文出现的关键词也能查到。选择该处后，用户能直接看到匹配文字及其上下文。
- [x] 查找栏显示当前匹配序号和总数。按 `Enter` 或 `Shift+Enter` 分别移到下一处或上一处，并高亮对应文字。同一句中出现两次的关键词能分两次定位。
- [x] 当匹配文字位于已折叠的助手过程段时，总数包含该处。定位到它时自动展开相应过程段，滚动到匹配文字并高亮，无需手动展开。
- [x] 按 `Esc` 关闭查找并清除高亮，保留当前阅读位置。切换会话后，上一会话的关键词、计数和高亮均清空。
