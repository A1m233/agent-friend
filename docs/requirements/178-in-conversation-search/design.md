# 178 当前会话内查找 · 技术方案

## 状态

CONFIRMED

## 范围

按[需求文档](./requirement.md)在对话页实现会话内查找。

## 正文与匹配

会话搜索服务按会话 ID 读取有效历史，复用既有的用户可见消息投影，给前端返回按时间排列的正文块、角色和事件锚点。工具数据和附件无需传输。用户气泡显示纯文本，查找保留其中的字面符号。助手正文使用聊天的 Markdown 引擎提取显示文字，跳过隐藏链接地址和格式标记。两类正文使用同一套连续文本匹配规则计算块内的出现序号。查找结束后释放该会话的查找数据。

## 界面与导航

在会话面板内挂载查找栏并接管本页的单独查找快捷键。查找栏维护查询、匹配计数及当前位置，使用按钮或键盘循环导航。全局搜索继续使用原快捷键。

复用会话 store 的历史分页和消息列表的事件锚点导航。选中一次匹配时，先加载对应事件，再按既有折叠策略展开目标段，待正文实际挂载后定位并高亮具体文字范围。切换查询、关闭或离开会话时取消旧导航，迟到的请求不能更新新状态。

## 验证

专项测试覆盖会话隔离、可见文字、重复匹配和定位。Windows Tauri 验收覆盖原生快捷键、窗口移动与缩放、长历史、过程段展开和关闭后的阅读位置。
