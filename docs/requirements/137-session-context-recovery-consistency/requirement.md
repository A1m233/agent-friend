# 137 · 会话上下文与任务恢复一致性

## 状态

CONFIRMED

确认日期：2026-09-19。

## 背景

一个已有长会话在切换思考强度后，尚未开始业务便触发压缩；调大窗口后依旧失败。编辑重发又漏存了具体错误，造成重新读取历史时缺少失败原因。切回原思考强度后，发送前的历史重建将模型历史从 60 条扩大到 1,193 条，再次触发压缩。该次压缩成功，但旧任务的中断提示被追加到当前请求之后，影响了对当前任务执行状态的理解。

这些问题涉及计量、模型历史、运行生命周期和错误呈现的交界，不能只修改某一条提示或让用户更换配置。证据、反证及诊断结论的修订统一记录在 [evidence-index.md](./evidence-index.md)。

## 目标

- 未变化的历史保持有效的计量依据，不因无关配置变化被当作大量未知输入。
- 发送、恢复和压缩承接同一份有效模型历史，保留最新目标、修正和已确认执行结果。
- 用户始终能看见与当前任务对应的失败原因，刷新或重开会话不丢失其语义。
- 中断及副作用提示准确归属于具体任务，不把旧任务状态投射为当前任务状态。
- 检查并修复同机制的相邻缺口，验证完整入口路径而非仅验证局部 helper。

## 范围

### 包含

1. 检查思考强度、窗口配置、模型及连接变化对计量有效性的影响；保留可复用证据，对真正不兼容或未知的内容明确处理。不将输入成本未知等同于每段独占整个窗口，也不无证据低估成本。
2. 压缩前评估必要性和可行性；避免无法解决保留部分预算问题时仍生成无效摘要。失败保持原历史，并能解释具体原因。
3. 核对正常发送、编辑重发后失败、用户再次发送、继续和重启恢复的模型历史；避免无关状态变化重引已替换的历史、破坏有效摘要或遗失当前任务。
4. 统一受影响入口的失败事实、错误原因、恢复能力与呈现；覆盖没有任何 assistant 正文便失败、编辑重发失败、重复失败以及重新加载。
5. 约束中断提示的任务归属、时间、有效范围及去重；区分尚未开始工具、已完成、仍在执行和结果未知。真正未知的副作用仍须核实，不因本次修复而盲目重放。
6. 按上述机制检查普通发送、编辑重发、继续、重启、配置切换，以及桌面、IM、语音和后台调用方。记录每条路径的结论和覆盖情况；同机制问题纳入本需求，独立问题单列并说明边界。
7. 用脱敏的真实事故形态建立确定性回归，覆盖实际恢复、重建、压缩、provider 请求装配、错误持久化和历史投影边界。

### 不包含

- 修改业务 Skill、替用户重跑游戏任务或直接改写用户真实会话历史。
- 重建整套 Agent 运行框架、增加平行会话存储或通用工作流引擎。
- 自动切换模型、扩大权限、无界重试或保证任意外部副作用 exactly-once。
- 将第三方模型、网络或业务环境故障作为本产品代码能够消除的问题。

## 验收条件

- [x] **AC-01 配置与计量**：同模型仅改变思考强度或窗口上限时，未变化且仍适用的计量证据可复用；模型、路由或内容真正不兼容时保持保守且可解释的行为。
- [x] **AC-02 压缩可行性**：已知无法通过摘要解决的预算失败在调用摘要前识别；成功压缩经过最终候选复核，失败不丢历史，真实超窗保护仍有效。
- [x] **AC-03 历史连续性**：完整发送入口覆盖编辑重发失败后再次发送、模型配置变化及重启恢复；保留已提交模型历史与合法 checkpoint，不因 bookkeeping 差异无故恢复全量旧历史。
- [x] **AC-04 当前任务保真**：压缩前后均保留最近用户目标和修正；新任务不被旧中断、旧摘要中的未决事项或旧恢复记录替代。
- [x] **AC-05 中断事实归属**：多个旧中断、新任务、同任务继续、重复恢复分别验证；模型可见状态具有明确归属，未执行不写成可能已执行，未知不写成未执行。
- [x] **AC-06 错误持久化**：普通发送、编辑重发和继续在正文生成前或生成中失败，均保留所属运行的原因；刷新、重开及多次失败不产生丢失原因或错误串轮。
- [x] **AC-07 副作用与权限**：历史恢复不重放已完成动作、不恢复过期权限、不重启用户已停止任务；仍运行或结果未知的工具不被当作可直接重试。
- [x] **AC-08 相邻路径**：桌面、IM、语音和后台入口完成有边界的同类盘点；受影响链路有验证，未覆盖或不可复现的部分明确记录。
- [x] **AC-09 证据与完整入口验证**：回归经过真实产品组装边界，记录计数模式、重建原因、checkpoint 状态、运行归属及失败阶段；局部离线计数不冒充完整运行或模型行为验收。
- [x] **AC-10 项目门禁**：相关确定性测试和 `scripts/check` 全绿，用户确认验收；真实 LLM、桌面视觉和安装包验证按实际授权与影响分类执行，缺口如实记录。
