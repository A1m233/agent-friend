# 模型设置交互整理与自定义连接

## 状态
CONFIRMED（2026-09-10 用户确认本轮推理强度、默认选择与现有附件格式接入范围；设计修订待确认）

## 背景与目标
现有模型选择、模型凭据和工具服务凭据纵向混排。先整理前端交互，让用户快速找到模型与对应凭据，再由用户检查效果。

## 范围
- 第一步：模型与服务凭据分为两个页签；模型页顶部集中放新对话默认模型、记忆模型；供应商以紧凑列表呈现状态，点击编辑展开表单。
- 保留既有凭据保存、校验、应用、错误反馈及模型选择语义。
- 第一步不包含自定义接入；第二步范围在用户验收第一步后确认，见下文。

## 第二步：自定义模型连接
2026-09-09 用户确认以下完整范围；第二步技术方案另行确认：
- 在模型页添加、编辑、删除自定义连接，填写连接名称、Base URL、API Key 和 Model Name；支持多个连接，每个连接管理多个模型，同名模型按连接区分。
- 协议支持 OpenAI 兼容 Chat Completions 与 Responses；本期不加入 Anthropic Messages。
- 填写地址和密钥后即可在未保存草稿上获取模型列表，通过搜索和勾选添加多个模型；服务不提供列表或读取失败时仍允许手填模型名。
- 自定义模型可用于会话切换、默认对话与记忆处理；配置及模型选择重启后保留。连接失效时明确提示，不默默切换到其他服务。
- 保存配置与主动测试分开；API Key 沿用系统凭据库，测试调用明确由用户发起并反馈鉴权、模型、协议及网络错误。
- 本期覆盖文本、流式、工具调用、OpenAI 格式的自定义推理强度，以及现有附件格式；上下文长度优先读取可靠信息，无法确定时提示用户补填。新增范围详见下文。
- 实现应保持连接、模型、凭据与请求协议职责解耦，避免新增服务需要修改多处供应商分支。
- 最终合入前更新 guide，覆盖设置页交互及最终自定义接入流程。

### 推理强度与默认选择（2026-09-10 修订）
- 自定义连接仅采用 OpenAI Chat Completions / Responses 的推理强度格式；档位值允许自由填写，不以本地固定枚举或模型名称限制供应商支持范围。
- 推理强度可从常见建议中选择，也可手填；建议不得标为服务已确认支持的档位。当前不承诺标准模型列表可返回推理档位；未来有可靠元数据时仍保留手填。
- “使用服务默认值”独立于显式关闭或其他档位值，表示不指定强度。服务拒绝时明确反馈，不静默删参数、降档或换服务；服务成功接收不等于已证明实际执行该档位。
- 默认对话模型、记忆模型均可设置强度；会话内可覆盖。沿用既有默认模型的生效边界，正在执行的轮次与工具循环不被中途改变，旧设置保持兼容。
- 用户界面显示连接和模型的可读名称，不展示内部自定义 UUID；区分能力未知、应用未接入、服务拒绝，不再以“不支持”笼统表示自定义强度未配置。

### 自定义附件（2026-09-10 修订）
- 自定义连接必须实际支持现有 JPEG、PNG、WebP、PDF、TXT 附件流程；本期不增加格式，不以仅放开入口或修改提示视为完成。
- 模型附件能力允许用户声明或覆盖；不因未登记到内置模型目录就一律禁止。协议适配与能力信息分开，图片和文档分别处理。
- 复用已有附件选择、存储及数量/大小约束；类型校验、发送失败恢复、历史续聊、重启恢复与模型切换均须保持一致。
- 附件内容发给用户选定的连接；不暗中改用其他供应商或辅助模型。无法处理时明确说明，不能把丢失图片或文档内容当作处理成功。
- 文件原生传输与本地提取的具体策略在技术方案比较确定，但须明确文字和扫描/图像内容的覆盖与限制，避免笼统承诺全部 PDF 内容均可读取。

### 连接生命周期
- 编辑连接从下一次执行生效；正在进行的一轮对话及工具循环保持原配置，后台任务也在各自执行边界应用新配置。
- 删除前必须替换该连接承担的默认对话、记忆用途，删除界面提供替换入口；不得暗中改用其他服务。
- 连接仍有相关执行时，先等待其结束或由用户停止，再删除。
- 删除连接保留历史内容及模型标识。旧会话始终可读，继续执行时检查模型可用性，必要时要求选择可用模型。

### Responses 覆盖与兼容
- 已确认支持 Responses 的连接覆盖流式和非流式调用，包括记忆、上下文压缩和通知；保留 Chat Completions 兼容，不把未知兼容性的现有模型强制迁移。
- 最终文本提取必须区分过程说明与消费方需要的结果，不能让 commentary 污染记忆 JSON。
- 迁移覆盖 JSON、工具循环、异常结束、请求参数及实际请求路由；评测入口同步验证，不以产品路径通过替代评测路径证据。
- 严格 JSON Schema 单独评估，不随传输迁移默认启用；兼容既有配置和历史数据。
