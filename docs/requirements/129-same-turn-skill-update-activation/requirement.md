# 已有 Skill 更新后同轮使用

## 状态

CONFIRMED

## 背景

当前 Skill 内容在用户轮开始后发生变化时，激活会被拒绝并要求下一轮重试。用户要求“更新 Skill，然后继续任务”时，即使更新成功，也必须额外发送消息才能继续。

需求 108 曾研究这一问题，后封存而未实现。本需求独立交付，保留 108 的历史记录；目标是让已有 Skill 更新后在当前用户轮继续使用新版，包括更新前已经加载过旧版的情况。

## 目标

- 已有 Skill 更新成功后，原任务在同一用户轮按新版继续，无需用户重发消息、重开会话或重启应用。
- 本轮已激活的 Skill 更新成功时自动重新加载新版；尚未激活的 Skill 在后续使用时加载最新版。
- 明确每次实际使用的版本，保持正文、引用资料及脚本的一致性，不篡改已发生的操作与历史。

## 范围

### 包含

- 对当前轮已知的已有 Skill，支持首次激活及同轮再次激活时使用当前有效版本，不以轮初版本或首次激活版本锁死整轮。
- 本轮已经激活旧版时，经运行时确认的受支持更新成功后，自动加载并切换到新版；向模型提供新版内容及后续使用新版的明确说明，不要求用户或 Agent 额外补一个手动步骤。
- 本轮尚未激活时，更新成功只刷新可用版本，不主动加载正文；后续首次使用直接加载新版。
- 保留同轮再次激活能力；相同版本、相同内容不重复注入，版本发生变化时明确形成新绑定。
- 后续受 Skill 绑定的正文、包内文件读取及命令执行使用一致的版本。切换不替换正在运行的旧版命令的资源，也不追溯重做已完成的操作。
- 更新结果与激活结果分别如实呈现。更新失败保留原绑定；更新成功但新版加载失败时，明确说明失败阶段，不自动把旧版执行当作新版任务的继续。
- 继续检查目标身份、有效性、调用策略和权限。自动重载不扩大原有文件、命令、网络或其它副作用授权。
- 对复用统一 Skill 运行时的入口保持一致行为，并覆盖更新、重新激活、资源版本和失败恢复的回归验证。

### 不包含

- 轮初未知、首次安装的 Skill 在同轮加入可用候选集；本期聚焦已有 Skill。
- 后台自动更新、批量更新、Skill 商店或新增管理界面。
- 任意外部文件变更都自动替换已加载内容；自动重载由运行时确认的受支持更新成功触发。
- 改写旧版会话历史、自动重跑已完成操作，或将正在运行的命令中途切换到新脚本。
- 改变既有更新来源、冲突处理、接管和外部调用授权规则。

## 关键信息

- “同一轮”指同一条用户请求的完整执行过程，包含多个模型步骤和工具调用。
- “已激活”指当前轮真实加载成功，不以历史中的加载记录或模型自报为依据。
- “自动加载新版”由可信更新结果触发，不能通过匹配命令输出中的成功措辞或 Agent 的自然语言声明实现成功认定。
- 已加载内容保持稳定与同轮切换新版可以共存：切换以新的成功激活为边界，旧版作为历史保留，后续使用新版。
- 本需求实现并验收前，需求 076、088 的现行运行时行为不变；验收后，本需求取代其中要求已有 Skill 轮内更新必须等待下一用户轮的口径。

## 验收条件

- [ ] **AC-1 未激活时更新**：当前轮已知但未激活的 Skill 更新成功后不自动注入正文；之后首次激活加载新版并继续任务，无需额外用户消息。
- [ ] **AC-2 已激活时更新**：本轮已加载 V1，更新成功为 V2 后自动加载 V2，模型获得新版指引，后续任务按 V2 继续，无需手动重新激活。
- [ ] **AC-3 同轮再次激活**：本轮已加载旧版时可再次激活当前有效新版，不返回仅由轮初版本不一致导致的拒绝；同版本相同内容重复激活不重复注入。
- [ ] **AC-4 版本一致性**：V2 激活后的正文、包内引用及新启动的 Skill 命令均绑定 V2，不复用仅按 Skill 身份缓存的 V1 资源；已启动的 V1 命令保持其原资源，正常结束和取消均可清理。
- [ ] **AC-5 历史与连续性**：V1 历史及已完成操作不被改写或自动重跑；连续成功更新后后续操作使用最近一次成功激活的版本。
- [ ] **AC-6 失败分层**：更新失败、更新成功但加载失败、无效内容、目标删除及权限拒绝分别有真实结果，不宣称新版已生效，也不悄悄以旧版冒充新版继续。
- [ ] **AC-7 无变化与未激活隔离**：无实际版本变化时不反复注入；更新未激活 Skill 不改变其它已激活 Skill。
- [ ] **AC-8 可信触发与授权**：伪造成功文案不能触发自动重载；宿主显式激活和允许的模型激活均能正确更新，禁止的隐式调用和未授权副作用不能借重新激活绕过。
- [ ] **AC-9 既有能力兼容**：后续轮发现新版、历史恢复、上下文压缩及统一运行时调用入口不回归；旧版资源不会被误报为当前有效绑定。
- [ ] **AC-10 验证**：核心行为有确定性自动化测试，项目完整检查通过；真实模型行为验证如需执行，按相应授权流程另行安排，不以未运行替代通过。
