# 沙箱故障静默恢复与任务续接

## 状态

CONFIRMED（2026-09-24 用户确认范围、静默体验、UAC 与安全续接边界）

## 背景

本地命令执行过程中，沙箱可能在先前正常工作后突然不可用。当前故障可能直接成为工具失败结果，导致 Agent 停止并回答；用户随后修复环境、重新发送“继续”，才能重新推进任务。环境可恢复却中断任务，造成额外操作、模型调用和重复执行风险。

## 目标

在首次执行、任务中途、后续工具调用和并发任务场景下，尽可能在原工具调用内部静默恢复可恢复故障。保留用户任务、执行进度和有效授权；恢复成功后安全续接，不需要用户重新发消息，也不引入专门决定如何修复的 LLM 调用。

## 范围

### 包含

- 复用现有沙箱修复能力，增加自动触发、恢复协调、验证和任务续接。
- 区分可恢复的执行环境故障、需要系统确认的初始化，以及业务失败、权限拒绝等不应触发修复的情况。
- 覆盖命令尚未启动、启动确认丢失、命令运行中、后续观察或读取结果失败等阶段；按可证明的执行状态决定续接方式。
- 可恢复故障不提前向模型提交终态失败，不让 Agent 为恢复环境提前结束当前任务或重新规划业务。
- 默认不新增专门的恢复弹窗、聊天消息、通知或进度文案；保留原工具调用的等待状态及取消能力。Windows 必需的 UAC 提示允许出现。
- 多任务遇到同一环境故障时协调恢复，避免重复提权、相互重置或因恢复中状态再次触发恢复；保护未受影响的在途任务。
- 恢复有次数和时间边界；协调已有底层恢复，避免层层重试放大。用户取消、授权撤销、恢复失败或预算耗尽后不再自动续跑。
- 恢复成功必须有实际可用性验证；保存首次可见故障、恢复尝试、验证和续接结果，供诊断复核。
- 统一执行入口的恢复语义；桌面、IM、定时任务等入口不能各自形成不同的重试规则。无人处理 UAC 时有界等待，不假定系统确认已完成。

### 不包含

- 本需求不以彻底查清既有现场沙箱根因为前置条件，也不宣称自动恢复等同根治。
- 不修改底层沙箱隔离机制，不自编译或替换 Codex，不默认降低隔离强度或转为宿主无沙箱执行。
- 不保证任意已中断程序可从原指令位置恢复，不自动重放结果未知且可能存在副作用的业务命令。
- 不建立通用业务工作流引擎，不自动重新执行整段会话或整轮业务任务。
- 不把安装、付费 LLM 验证或现场系统修改纳入隐含授权。

## 关键行为边界

环境恢复与业务重试分别判断。尚未启动且授权仍有效的操作可以在原调用内继续；仍在运行的操作优先恢复观察，不重复启动；已完成操作复用可验证结果；启动或完成状态未知时先核对现有执行证据，无法确定则如实交付未确认结果，不假装成功。

恢复仅隐藏能够成功处理的中间环境故障。真正不可恢复、需要用户处理或无法安全续接时，才向 Agent 和用户交付最终故障及已完成、未执行和未知的边界。正常工具完成后的模型续接属于原流程，不属于本需求禁止的额外修复决策调用。

## 验收条件

- [ ] AC-1：首次调用及任务中途出现可恢复沙箱故障时，在原工具调用内完成恢复、验证和安全续接；用户不必去设置页或另发“继续”。
- [ ] AC-2：成功恢复路径没有中间终态失败进入模型历史，不因故障提前产生最终回答，不新增用于选择修复动作的模型调用；正常后续模型调用不受影响。
- [ ] AC-3：成功路径不新增专门恢复提示、消息或通知；原工具等待状态保持真实且可取消。需要提权时允许 UAC，拒绝、超时或取消后不会反复弹出或继续业务。
- [ ] AC-4：未启动、启动确认丢失、运行中、已完成、结果未知分别有明确续接行为与故障注入证据；有副作用命令不因丢失响应或恢复环境而重复执行。
- [ ] AC-5：多个会话和并发工具同时遇到同一故障时不会重复初始化或互相覆盖恢复结果；一个任务取消不误取消其他任务，恢复不无声终止健康的在途操作。
- [ ] AC-6：自动恢复有统一且可测试的次数、等待和复发限制；底层与外层尝试不会无界相乘。持续失败最终有界结束并保留原任务事实。
- [ ] AC-7：恢复前后权限边界不扩大；续接仍绑定原调用和有效授权。权限拒绝、业务退出失败及普通文件权限错误不会被笼统当作沙箱损坏。
- [ ] AC-8：仅状态文件存在、helper 可加载或修复命令退出成功不足以宣布恢复；实际执行验证失败时不得继续原业务。
- [ ] AC-9：诊断可关联故障、恢复、验证与续接，区分已知和未知的首次原因；不新增凭据、任意命令正文或用户文件内容泄漏。
- [ ] AC-10：入口盘点覆盖桌面、IM、定时任务及直接执行调用；无桌面交互时需要 UAC 的场景不无限等待，也不绕过确认。
- [ ] AC-11：故障注入、取消、并发、预算及重复副作用防护通过自动化验证；项目检查通过。Windows 真实恢复与用户体验验收单列证据，未执行不得标为通过。
