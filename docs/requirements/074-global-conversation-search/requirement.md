# 全局会话搜索

## 状态

CONFIRMED

## 背景

对话消息列表使用虚拟化渲染，离开可视区域的历史消息不会持续挂载在桌面 WebView DOM 中。因此，系统原生的 `Ctrl+F` / `Cmd+F` 只能查找当前已渲染的局部内容，无法可靠覆盖长会话，更无法跨多个会话查找历史消息。

[issue 042](../../issues/042-chat-message-search-navigation/README.md) 已登记当前会话缺少完整消息搜索与定位的问题。本需求将解决方向扩展为对话页的产品内全局搜索：用户从一个统一入口检索本机可访问的全部会话，并从结果直接返回具体消息位置，不再额外复刻浏览器式的当前会话查找工具条。

## 目标

- 在对话页提供始终可发现的全局搜索入口，入口外观看起来像搜索框，但交互语义是打开搜索面板的按钮。
- 提供应用内 Apple Spotlight 风格的居中搜索面板，让用户通过鼠标或键盘完成输入、浏览结果和选择。
- 搜索覆盖普通会话与已归档会话的标题和用户可见内容，不受当前会话、当前滚动位置或虚拟列表挂载范围限制。
- 用户选择消息结果后，能够打开对应会话、定位到具体消息并看到明确的命中高亮。
- 尽可能复用社区成熟的全局搜索 / command palette 实现承载通用交互能力，避免自行实现已有成熟方案覆盖的弹层、焦点、快捷键、键盘导航、结果选择和无障碍机制。

## 范围

### 包含

#### 搜索入口与面板

- 在对话页会话侧栏顶部加入搜索框式按钮，清楚表达“搜索全部对话”。
- 点击入口后，在当前 agent-friend 窗口内打开 Spotlight 风格的居中宽面板，并自动聚焦真实搜索输入框。
- 在对话页按 `Ctrl+F`（Windows / Linux）或 `Cmd+F`（macOS）时，阻止 WebView 原生页面查找并打开同一个全局搜索面板。
- 面板支持关闭后将焦点恢复到合理位置，不打断当前会话状态。

#### 搜索范围

- 搜索本机仍然存在的全部普通会话与已归档会话。
- 搜索会话的当前展示标题。
- 搜索用户消息正文。
- 搜索助手最终呈现给用户的可见文本。
- 搜索用户可见的附件文件名，但不读取附件正文，也不执行 OCR。
- 搜索结果不依赖消息是否正在当前 WebView DOM 中渲染。

以下内容不进入搜索语料：

- 隐藏的系统事件与内部控制事件。
- reasoning / thinking 等未向用户展示的内部内容。
- 工具调用参数、工具原始结果及仅用于运行时编排的技术字段。
- 已硬删除的会话。
- 尚未持久化完成的流式临时文本。

#### 匹配与结果展示

- 首期提供确定性的关键词文本匹配，不引入 LLM、记忆召回或语义搜索。
- 文本匹配不区分英文大小写，并能直接匹配连续的中文关键词或原话片段。
- 会话标题命中时提供会话级结果；选择后打开对应会话。
- 消息内容命中时以用户可见消息为结果单位，至少展示会话标题、消息时间、消息角色和包含命中词的上下文片段。
- 结果片段高亮所有可见命中词；当前键盘选中的结果具有清晰状态。
- 已归档会话的所有结果展示明确的“已归档”标签。
- 搜索面板覆盖输入前提示、搜索中、无结果、失败和有结果状态。

#### 键盘与选择行为

- 支持通过上 / 下方向键在结果之间移动。
- 支持按 Enter 打开当前选中的结果。
- 支持按 Esc 关闭搜索面板。
- 鼠标点击和键盘选择产生一致的打开与定位结果。

#### 会话打开与消息定位

- 选择普通会话中的消息结果后，打开对应会话并滚动到目标消息。
- 选择当前会话中的离屏消息结果时，同样能够驱动虚拟列表挂载并定位目标消息。
- 定位完成后对目标消息及其命中词提供短暂且清晰的高亮反馈。
- 选择已归档会话结果后可以直接查看对应会话或消息，但不得隐式取消归档。
- 打开搜索结果不得创建新会话、复制消息或改变原会话内容。

### 不包含

- 单独的当前会话搜索框、上一条 / 下一条匹配工具条或另一套 `Ctrl+F` 交互。
- 在 agent-friend 未聚焦时仍可通过系统级全局快捷键唤起的独立 Spotlight 窗口。
- 跨设备、云端或其他用户数据源的搜索。
- LLM 语义搜索、向量搜索、模糊问答或由 Agent 总结搜索结果。
- 按角色、日期、模型、Persona、附件类型等条件做高级筛选。
- 搜索附件正文、图片文字、工具调用详情、隐藏事件或内部诊断数据。
- 在搜索结果中直接取消归档、重命名或删除会话。

## 关键信息

- 关联问题：[issue 042 · 长会话缺少完整的对话内搜索与消息定位](../../issues/042-chat-message-search-navigation/README.md)。本需求以统一全局搜索覆盖其核心查找与消息定位问题。
- 对话页现有消息虚拟化不能成为搜索范围的限制；搜索必须基于完整、持久化且用户可见的会话数据。
- 已归档会话仍可检索，但结果必须标记归档状态，打开结果不得改变归档状态。
- 通用搜索面板能力优先复用成熟社区实现；候选库、兼容性验证和最终技术选型在 `design.md` 中确定。
- 本期“Spotlight 风格”仅描述 agent-friend 窗口内的入口、弹层和键盘体验，不表示创建操作系统级全局窗口。

## 验收条件

- [x] 对话页侧栏顶部展示搜索框式按钮；点击后打开应用内居中宽搜索面板，输入框自动获得焦点。
- [x] 在对话页按 `Ctrl+F` / `Cmd+F` 打开同一个全局搜索面板，而不是 WebView 原生查找界面。
- [x] 输入关键词后能够匹配非当前会话和当前会话离屏区域中的用户消息与助手可见文本。
- [x] 搜索能够匹配会话展示标题和可见附件文件名。
- [x] 英文匹配不区分大小写，中文连续关键词能够直接匹配。
- [x] 搜索结果展示会话标题、消息时间、消息角色和命中上下文，并高亮关键词。
- [x] 已归档会话的结果展示明确的“已归档”标签。
- [x] 选择普通会话的消息结果后，应用打开对应会话、滚动到目标消息并提供目标高亮。
- [x] 选择当前会话的离屏消息结果后，虚拟列表能够挂载并定位目标消息。
- [x] 选择已归档会话结果后可以查看目标内容，且会话仍保持归档状态。
- [x] 上 / 下方向键、Enter、Esc 以及鼠标点击均能按预期操作搜索面板和结果。
- [x] 搜索面板对输入前、加载中、无结果、失败和有结果状态提供明确反馈。
- [x] 搜索不会命中隐藏系统事件、reasoning、工具参数、工具原始结果、附件正文或已删除会话。
- [x] 通用弹层、焦点、快捷键、键盘导航、结果选择和无障碍能力采用经技术方案确认的成熟社区实现；若某项必须自研，技术方案中有明确的不适用证据与边界说明。
- [x] 关闭搜索面板不会改变当前会话内容、归档状态或正在执行的对话任务。
