# 179 首次使用引导 · 技术方案

状态：CONFIRMED，2026-11-15。需求见 [requirement.md](./requirement.md)。

## 桌面入口和生命周期

启动时读取桌面设置的 `onboardingCompleted`。新安装与缺少该字段的旧设置均按 false 处理。正常启动仅检查一次，未完成时显示无父窗口的 Tauri「设置助理」。开发版 Action Bar 末尾的调试按钮与本机 open 命令指向同一窗口，按需创建，已打开时聚焦。系统关闭按钮只关闭向导，其他窗口保持可操作。记忆模型页确认两项默认模型就绪后保存完成标记，写入成功才进入就绪页。继续体验个性化的用户可在末页打开使用选定模型的新对话。

## 必选与可选配置

设置助理使用 820 × 660 逻辑像素的内容区，禁用拖边缩放和最大化。打开或移动到其他屏幕时，根据该屏的工作区、缩放比例及原生窗口边框缩小超出的维度；空间充足时使用标准尺寸。长表单在正文内滚动，步骤导航固定在底部。

必选顺序为服务连接、默认对话模型、默认记忆模型。复用内置凭据校验、自定义连接编辑器、模型目录与默认模型写入逻辑。只根据已保存且可用的连接允许继续。返回或重新打开时重新读取状态，保留当前窗口内的表单。连接缺失、应用失败与服务离线要可区分。

桌面端独立记录是否已处理首个可用模型。首次检查时已有可用模型的安装保留原选择。空配置在内置服务或 BYOK 首次应用成功后读取可用目录，优先采用当前默认对话模型，若该模型不在目录中则采用第一项。两个默认用途与一次性标记一起保存，重新启动后也能恢复待处理状态。

就绪页与可选页统一用「上一步／继续」，末页将前进按钮改为「完成并开始使用」。语音转写可独立提交新版 APP Key 或旧版 ID/token；不要求开通 RTC。人格复用当前人格与候选对话编辑器，只有明确应用才变更人格；陪伴与通知复用原设置。

## Agent 配置协助

Guide Skill 是首次使用流程的知识来源，以同一章节连接用户界面、外部 Agent 与 AF。可执行操作限于查询非敏感配置状态、打开引导、选择已配置模型作为默认值；Key 在桌面页录入。读取模型目录和验证状态复用运行中 bridge，改变桌面设置和打开引导经桌面所有者执行，避免并发写 settings.json。Guide 按用户实际版本说明支持范围。外部 Agent 及具备命令能力的 AF 通过同一受支持的本机入口操作，避免维护两套写入逻辑。

## 验证

覆盖两个用途、不同服务、失效连接、导航往返、重复进入和非敏感配置接口。运行前后端与原生门禁，在当前 worktree 的 Tauri 实例验证按钮能打开、往返、退出。在线生成、人格模型调用和实际麦克风转写的证据另行记录。
