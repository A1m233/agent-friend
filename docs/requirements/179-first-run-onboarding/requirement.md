# 179 首次使用引导

状态：CONFIRMED。2026-11-15 确认需求范围，现状核对基线为主干 `68fef40d`。

## 用户第一次打开 AF

设置助理使用固定的 820 × 660 窗口，用户可以移动、最小化和关闭窗口。窗口无法拖边缩放或最大化；小屏幕按可用工作区自动缩小。长内容在窗口内滚动，「上一步」与当前步骤的主要操作始终可达。

AF 启动时，若尚无向导完成记录，自动打开独立的「设置助理」窗口。用户随时可以关闭，照常操作桌宠、聊天与其他窗口。确认基础配置前关闭，下次启动仍提示。确认两项默认模型并进入「这下可以开聊啦！」时，AF 记住引导已完成。之后可以直接关窗，也可以继续个性化设置；再次启动、模型变更或凭据失效都不会重新触发欢迎窗口。已经配好模型的用户可以沿用原配置完成。

开发版在桌宠 Action Bar 的调试工具末尾提供「新手引导」，方便调试。正式版通过独立设置助理完成首次引导。手动打开与首次欢迎进入同一套教程，读取当前配置；教程已打开时回到已有页面，重入不会清空已配好的模型、人格或用户正在填写的内容。

首屏由 Echo 欢迎用户，提供「一起设置」入口。想请自己的 Agent 协助时，可以直接阅读提示词全文，并在旁边点击「复制提示词」。两条路径共用同一组基础配置完成条件。去申请 Key、切到外部 Agent、关窗或重启后，应能接着处理尚缺的项目；已生效的配置可以直接沿用。老用户升级、迁入设置或只配了一部分时，应依据现状识别，保留原选择。

## 先完成三项必选配置

| 顺序 | 用户需要完成什么 | 怎样判断可以继续 |
| --- | --- | --- |
| 1. 连接模型服务 | 选择内置 DeepSeek、Kimi 或自定义连接（BYOK）。BYOK 是首屏配置路径之一，允许填写服务地址、协议、API Key，从列表选择或手动添加模型，必要时补上下文长度。 | 拟选用途引用的连接和模型已保存、凭据可用且配置已应用。两项用途若来自不同服务，则分别检查各自凭据。 |
| 2. 确认默认对话模型 | 告诉用户这决定以后新建对话时由哪个模型回复；展示已有选择，允许改选内置或自定义模型。 | 默认对话模型指向已配置的服务。引导结束后打开的第一段对话实际使用该模型，包括进入配置前已经打开草稿的情况。 |
| 3. 确认默认记忆模型 | 说明 AF 使用它处理长期记忆。提供沿用对话模型的简便选项，也允许单独选择其他已配置模型。 | 默认记忆模型有可用连接并已对记忆服务生效。仅配置 Kimi 或 BYOK 的用户也能完成全部必选项。 |

必选步骤没有「稍后设置」。保存失败、凭据有误、模型已移除、配置已保存但尚未应用时，指出具体缺项并允许修正或重试。已有有效默认值可直接确认；两项用途共用连接时只需录入一次 Key。

首次从没有可用模型变为有可用模型时，AF 自动把同一个可用模型保存为默认对话模型和记忆模型。之后用户可以分别调整两项选择。后续新增或重连服务时保留用户的选择。

两项默认模型都确认后，说明用户可以关闭向导照常使用 AF，或点「继续」浏览个性化选项。自主陪伴、人格和语音输入均可随时在设置中调整。

## 可选设置

| 项目 | 用户为什么可能现在就想看 |
| --- | --- |
| 语音输入 | 用户可以在这一步直接填写火山语音 APP Key，或选择 APP ID + Access Token，保存并看到应用结果。语音输入用于转写，双向语音通话另需 RTC 等凭据。 |
| 人格与交流方式 | 新用户看到产品自带的 Echo，已有配置的用户看到当前人格。可以沿用原样，也可以在此基础上与 Echo 对话修改、继续补充、查看候选与变化，明确应用或放弃。 |
| 自主陪伴与通知 | 当前自主陪伴默认开启。用户能了解伙伴何时主动联系、后台活动可能产生的模型用量，并按需调整自主陪伴和气泡提示。 |

可选步骤沿用「上一步／继续」。用户可以原样继续，无需填入语音凭据或应用人格候选。最后一页提供「上一步／完成并开始使用」。往返页面不会撤销已保存的设置或自动应用人格候选。搜索、地图、天气、QQ 接入等按实际使用场景介绍。

## AF 与外部 Agent 共用的 Guide Skill

官方 Guide Skill 承载首次使用流程：每一步解决什么问题、哪些必选、需要用户准备什么、在 AF 哪个入口完成、怎样判断是否生效、失败后如何继续。首次使用章节引用已有模型、BYOK、语音和人格专题。AF 读取随产品可用的兼容版本，外部 Agent 通过首屏提示词找到公开 Skill。两边都能说明同一流程和配置方法；当前机器是否就绪以产品读取的实际状态为准。

首屏提供可直接复制的提示词，文案示意如下。

> 请帮我完成 agent-friend（AF）的首次配置。先阅读官方 Guide Skill：https://github.com/A1m233/agent-friend-guide ，仓库里的 Skill 在 `skills/agent-friend-guide`。请按我安装的版本，带我选择 DeepSeek、Kimi 或自定义连接（BYOK），配置连接并确认默认对话模型和默认记忆模型。我会在 AF 的凭据输入框里自己填 API Key。请帮我判断还缺哪一步，直到可以开始聊天。基础配置好后，再问我要不要设置语音输入、人格或自主陪伴。

用户在 AF 尚不能聊天时即可复制。仅阅读 Guide 并带用户操作界面，就应能完成一条路径；用户回到 AF 后，向导应能识别刚完成的配置。若后续提供受支持的自动配置入口，再更新提示词说明它能代办哪些操作。

## 技术方案需要评估

- **就绪判据。** 对话和记忆分别创建模型客户端，记忆客户端延迟创建。首条回复成功只验证了对话路径。本需求把两项用途都列为基础配置。需按内置和 BYOK 分别界定凭据校验、模型引用有效、服务应用成功与实际生成测试各能证明什么。BYOK 的模型发现或保存不会生成回答，另行触发的生成与工具测试可能计费。
- **两类 Agent 可以代办的动作。** 分别评估 AF 内置工具和外部 Agent 的路径。比较 Guide 说明配合桌面操作、可由 Skill 调用的受支持本机工具，以及其他公开配置接口，列出各自能查状态、打开设置、选择默认模型和提交配置的范围。当前开发者凭据脚本和桌面内部接口并未构成普通安装版的完整外部配置入口。
- **Guide 的配套更新。** 公开 Guide 已有模型、BYOK 和语音专题，“开始使用”仍是预留页。正式实现时核对对应版本的 Guide、离线首启说明与提示词，补齐从零配置和外部 Agent 可操作范围。

## 验收条件

- [ ] 启动时按完成记录自动打开独立向导，关闭后可继续日常使用，完成后再次启动不自动弹出。在开发版通过 Action Bar 手动打开、重复点击、完成后重新进入，都能查看同一套教程并保留已有配置。
- [ ] 干净普通安装分别走通内置渠道与仅 BYOK；覆盖对话与记忆选同一模型和选不同服务。任一必选用途缺少配置时提示具体缺项，修正后能继续。
- [ ] 基础配置完成后可直接进入日常对话，并使用刚选的模型；也可先进入个性化设置，跳过全部可选项后照常使用。
- [ ] 语音支持两种凭据组合；保存和应用有明确结果。可从人格退回语音修改，再继续向前；在本次引导中无需重填刚输入的内容。
- [ ] 人格初值与当前 AF 一致；从陪伴退回人格时保留编辑对话和未应用候选，只有用户选择应用才改变生效人格。
- [ ] 模型尚不可用时也能复制包含公开 Guide Skill 链接的提示词。AF 与外部 Agent 分别能据该 Skill 指明内置和 BYOK 的配置路径、两种默认用途及可选项；从外部协助返回后识别实际完成项。
