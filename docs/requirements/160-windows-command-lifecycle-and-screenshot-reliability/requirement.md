# Windows 截图可靠性与图片交付

## 状态

CONFIRMED（2026-10-11 用户确认拆分：160 独立交付截图闭环，底层准备取消与并发隔离保证移交后续需求）

## 背景

一次 Windows 桌面截图请求在命令准备阶段超时，未交付图片；对话结束后，准备进程仍继续处理用户目录中的权限。调查同时确认内置截图脚本的默认路径分支存在变量冲突。已内置 Skill 和依赖，不足以保证普通截图任务能可靠完成。

已有需求 124、139、141 分别覆盖命令可靠性、内置 Skill 与执行环境、沙箱恢复。本需求补齐本次事故暴露的截图输出权限范围、脚本兼容与图片交付缺口，不重新定义一般业务重试规则。Codex 升级、MXC 接入及底层准备生命周期保证另行推进，续办入口为 [issue 070](../../issues/070-codex-upgrade-and-mxc-integration/README.md)。诊断来源、运行版本和局限见 [evidence-index.md](./evidence-index.md)。

## 目标

- 用户要求截图时，能够获得真实、可读取和可展示的图片，指定保存位置时遵循其意图。
- 普通截图不因过大的授权范围触发无关目录的权限处理；合法宽范围任务仍遵循现有授权模式。
- 未确认执行结果或清理状态时如实报告，不能以对话结束代替实际进程收尾。

## 范围

### 包含

- Windows 内置 screenshot Skill 的路径、执行环境、错误与图片交付适配。
- 普通截图的明确且有限输出位置；用户指定外部位置时的对应范围授权。
- 命令启动前的大范围写权限检查，以及明确、可执行的收窄或授权指引。
- 截图在准备、启动、运行及交付失败时的结果表达与图片资源生命周期。
- 结果未知、清理未确认与真正完成的区分，以及关联截图事故所需的最小诊断证据。
- 现有固定执行后端下的截图兼容性验证、必要的最小脚本适配及资源完整性验证。
- 确定性回归、真实 Windows 验证、安装包运行环境验证，以及受影响的 Agent 行为回归。

### 不包含

- 后台、被遮挡或最小化窗口的独立内容捕获能力升级。
- 桌面点击、输入、游戏操作或通用电脑控制。
- 自动重放结果未知且可能有副作用的命令；自动降低沙箱隔离强度。
- 对用户目录做递归权限重置，或把历史本机现场恢复变成日常产品的隐含动作。
- 无关的 PDF、办公 Skill、模型及全局审批流程改造。
- Codex 执行后端升级、MXC 接入、底层准备 helper 的准确取消、迟到执行防护、无残留与并发隔离保证；这些事项已移交 issue 070 对应的后续独立需求。

## 关键行为边界

### 截图输出与交付

普通“截一张给我看”采用产品管理的会话输出位置，不要求整个用户目录可写。用户指定保存位置时，仅申请任务需要的范围。成功必须包含有效图片，而非仅命令退出成功；图片在交付后仍按会话文件生命周期可访问，不能因回合清理留下失效引用。

截图范围应符合用户请求。当前屏幕区域捕获的遮挡与最小化限制必须如实表达，不能把空白、错误目标或无效文件作为成功。

图片展示由宿主根据 `view_image` 的成功结果固定完成，不要求 Agent 另行调用发布动作或在回复中再次插入图片。工具卡片默认折叠，成功时显示“已查看一张图片”；展开后显示所查看图片的缩略图，点击缩略图使用现有图片放大预览交互。实时对话与历史恢复保持一致；图片不可用时明确提示，不生成虚假缩略图。该行为也适用于 Agent 自检时成功查看的图片，不另设“自检不展示”的默认规则。

### 大范围权限

对用户目录根、磁盘根等大范围写入，在启动前进行确定性判定。普通截图应有收窄路径；确有宽范围需求时明确呈现实际授权对象与影响，保持现有权限边界和授权模式，不增加绕过会话自动授权的强制人工确认。不能只依赖模型记住提示词，也不能一律禁用合法批量文件任务。

### 失败表达与资源生命周期

准备超时、取消或运行结果未知时，不宣称截图已成功或底层进程已经停止，不自动重复执行。清理失败或无法确认时保留可观察的未确认状态和归属证据；回合结束不等于底层收尾完成。已交付图片不能依赖会在回合结束时删除的临时文件。

本需求沿用现有沙箱与执行服务，不通过杀共享服务、隐式无沙箱回退来恢复截图。底层准备阶段准确取消与并发隔离的完整保证属于后续需求，不能用本次截图成功替代其验收。环境恢复继续遵循需求 141 的有效授权、预算与未知副作用不重放边界。

### 上游资源与兼容性

针对需求 139 的上游文件原样保留约束，本需求明确允许为 Windows 截图可用性实施必要的最小兼容补丁，保留精确来源、许可证、差异说明和内容摘要。其他上游资源继续遵循既有约定。本需求不升级、自编译替换或修补 Codex 执行后端。
