# 175 · 自主陪伴的内心回看、续写与首次联系

## 状态

CONFIRMED，2026-11-08 确认需求范围与验收条件。前置需求为 [169 · 自主陪伴](../169-autonomous-companionship/requirement.md) 和 [171 · 自主陪伴优化](../171-autonomous-companionship-optimization/requirement.md)。具体案例见[问题清单](./problems.md)。

## 背景与目标

用户问起 AF 最近在想什么时，普通聊天能按主题找回一些片段，却很难回答“再往前一次呢”。用户让 AF 以后都把新稿写进手记，AF 在下一次内心活动里读到了提醒，却在尝试申请前就判断自己没有权限。本期要让 AF 能查到自己做过什么，也能接着同一份作品往下做。

第一次活动时，新用户需要知道 AF 为什么会主动来聊，以及可以怎样告诉它自己的偏好。

## 范围与验收条件

### R1 · 普通聊天中回看 AF 自己的内心活动

提供专门的只读工具，让 AF 能直接翻阅自己的内心活动。用户可以从最近一次问起，也可以从已经搜到的片段追溯原文。回看保留活动的时间、来源与先后关系。过去的想法只作为历史资料，是否分享过以实际投递记录为依据。

- [ ] **AC-01** 有多轮活动时，连续问“上一次醒来写了什么”“再上一次呢”，AF 能分别找出对应的原文和时间，无需用户提供关键词或会话 ID。
- [ ] **AC-02** 普通聊天按主题搜到内心片段后，AF 能继续查看片段前后的原文。对于只记在心里的内容，AF 能说明当时留下了什么；只有具备投递依据时才称曾向用户分享。
- [ ] **AC-03** 尚无内心活动时，回看能返回空结果。读取失败时，AF 如实说明未能取得记录。两种情况下回看都不会创建活动、触发唤醒或发送消息。

### R2 · 在本轮权限下续写同一份手记

AF 得到的能力说明要与本轮实际可用的文件审批方式一致。自主活动可以申请自动审查时，AF 能为具体文件发起申请；QQ 已有可用审批渠道时，AF 能通过该渠道申请。对用户和 AF 可见的指南应准确说明文件、命令的审批条件。历史聊天中的文件引用可以帮助找到目标，能否读写按当前权限判断。

- [ ] **AC-04** 普通会话创建带旧稿的手记并留下文件引用。用户后来只说“以后都直接写到文档里”。内心活动有新稿时，AF 能从原聊天找回目标，获准后追加到同一文件。下一轮重新读回时，旧稿完整，AF 能指出具体新增的段落。
- [ ] **AC-05** 分别检查自主活动的自动审查和已登记的 QQ 审批。可申请时，能力说明和工具指引均给出正确路径。入口不可用、申请被拒或实际写入失败时，AF 能说明发生在哪一步，只在确实写入后称已保存。指南中的命令排障说明也与实际审批路径一致。

### R3 · 在首次内心活动时主动打招呼

仅在第一次内心活动加入介绍自主陪伴的提示。允许联系时，AF 用平时的口吻向用户发一条简短招呼，让用户知道，即使自己没先开口，AF 也会找感兴趣的事做，有时会主动来聊。介绍应让用户知道，可以随时用自己的话表达想让 AF 多做什么、什么时候来分享，也可以让它自行休息。用户无需当场回复或选择偏好。

- [ ] **AC-06** 首次活动允许联系时，招呼出现在用户可以回复的普通会话里。后续唤醒、重启或换到另一聊天渠道不会再次触发首次介绍。
- [ ] **AC-07** 有合适的普通会话时优先复用。用户完全没有普通会话时，招呼成为新桌面对话的第一条消息，用户可以在原处回复。发送前用户已创建合适会话时使用该会话。仅有归档普通会话时跳过招呼。同一发送即使重试也只产生一个目标对话和一条招呼。没有绑定 QQ 时只投递到桌面。
- [ ] **AC-08** 首次活动时若联系已暂停，跳过招呼，也不为它创建会话。恢复联系后按正常节奏活动，不专门补发介绍。
- [ ] **AC-09** 用户可以在聊天中说“多写点故事”“想摸鱼就摸鱼，有好玩的再来找我”。AF 在后续活动选择中可以参考这些偏好。“今晚别来找我”等明确的联系控制沿用已有暂停能力。
