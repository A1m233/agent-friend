# Windows 安装日志与诊断包

## 状态

CONFIRMED

## 背景

用户在 Windows 上点击“开始安装”后看到安装向导卡住、白屏，关闭后重试成功。旧安装器按构建保存日志，同一安装包重试会覆盖前一次记录。成功重试留下的日志只能说明这一次走完了哪些步骤。用户还需要从临时目录单独寻找日志，应用中导出的诊断压缩包只有当前安装状态。

## 目标与范围

- 从点击“开始安装”起，每次 Windows 安装尝试独立留档，能区分同一构建的多次尝试。
- 记录每个安装阶段的开始时间、结束时间及已知结果。在阶段中关闭或强制结束安装器后，已开始的阶段仍可辨认。
- 正常导出诊断压缩包时，自动带上本机最近 5 次可用的安装尝试日志，包含成功、失败和中断的尝试。旧版已有日志中可用的信息也应保留。
- 本需求用于定位安装卡顿，白屏根因及其修复另行调查。

## 验收条件

- [x] 同一安装包连续运行两次，第一次中断、第二次成功，重试前已经写入的记录仍可独立读取，两次都能对应到所用构建。
- [x] 从进入安装执行页起，正常完成的每个阶段都有开始和结束时间；中途强制退出时，可确定最后开始的阶段，并区分“没有结束记录”与“明确返回失败”。
- [x] 上述场景结束后，用户只需从应用导出一次诊断包，就能分别查看两次尝试的日志、时间顺序及各自最后一个已记录阶段。
- [x] 有超过 5 次可用记录时，诊断包收录最近 5 次；少于 5 次时按实际数量收录。旧日志缺少的逐阶段时间保持未知。
