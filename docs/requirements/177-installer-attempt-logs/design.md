# Windows 安装日志与诊断包设计

## 状态

CONFIRMED

## 安装器

NSIS 在进入安装执行页时建立本次日志。静默安装从第一个执行段进入同一个初始化函数。临时目录中的文件名携带产品、构建与尝试标识，使用独占新建语义。诊断写入失败沿用现有安装结果。

在环境检查、WebView2、辅助程序准备、预检查与旧进程处理、复制主程序、资源解压、系统注册、校验、激活及清理等操作边界分别写入 UTC 开始和结束时间。按实际执行记录凭据导入、目录迁移和回滚。每个事件写完即关闭文件。受控退出记录结果，强制中断保留最后已写入事件。资源文件按解压阶段计时。

## 诊断压缩包

Windows 导出端从临时目录识别对应产品及安装配置的日志，按尝试时间选最近五份，旧版以文件时间及原有阶段结果参与收录。只采集匹配的普通文件，限制读取体积，过滤机器路径和私有输出。包内附带逐次日志和索引，记录构建、时间、最后阶段与记录状态。机器契约和离线解析器同步增加这一证据族。

## 验证

检查交互和静默入口、各阶段成对计时、重试保留、旧日志兼容、五次限制与隐私过滤。隔离安装测试按本次新建文件识别运行，覆盖失败与重试；导出测试直接读取包含成功和中断记录的 ZIP。
