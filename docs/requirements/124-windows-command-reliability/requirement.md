# Windows 命令执行可靠性与故障诊断

## 状态

CONFIRMED

用户在本次会话确认需求范围、编号 124 和技术方案，已授权实现；当前处于实现验证阶段。

## 背景

用户 Windows 电脑上的命令执行多次出现沙箱初始化失败。历史截图显示沙箱初始化助手启动时提示“找不到指定的模块”。初始化恢复后，又出现已请求联网的 HTTPS 请求遭代理拒绝、Agent 切换执行方式后再次失败的现象。

已有调查确认产品就绪判断、受管联网配置和助手校验存在机制缺口，但尚未确定用户现场弹窗所指的具体模块。开发机没有复现该弹窗，不能以开发机测试通过代替用户现场验收。证据与置信度见 [evidence-index.md](./evidence-index.md)。

## 目标

- 已授权的 Windows 命令在有效沙箱内可靠执行，网络行为与授权一致。
- 用户能区分未初始化、需要修复、助手加载失败、网络拒绝和业务命令失败，并获得可执行的下一步。
- 修复动作以实际可用性为依据，不以状态文件存在或接口成功作为充分证明。
- 用户侧异常能通过一次有边界的诊断导出留下足够线索，减少反复试错。

## 范围

### 包含

1. 对齐联网授权和实际代理策略，区分产品管理与继承的代理来源，保留未授权联网的限制。
2. 对齐沙箱就绪条件与底层要求；处理初始化失败、状态失效、并发首条命令和显式修复后的状态反馈。
3. 覆盖命令运行时配套助手的完整性、可加载性和打包验证。
4. 为初始化和网络故障补充有界、脱敏、可关联构建与操作的诊断证据，保持旧诊断包可读。
5. 改善本故障链的工具错误和恢复指引；恢复路径不能指向确定不可用的执行环境，也不能把修复等同于业务命令已经重跑。
6. 分开记录本机确定性验证、对应 Windows 环境的安装产物验证和用户现场验收。

### 不包含

- MAA 的选关、游戏日、倍率、奖励或中断后游戏状态恢复策略。
- 关闭沙箱、默认改用宿主执行，或通过放宽未授权权限消除错误。
- 在缺乏证据时预先指定某个 DLL、运行库、杀毒软件或用户操作为根因。
- 未经现场授权修改用户账户、防火墙、代理、安装状态或清理沙箱现场。
- 通用工具参数体系重构、会话体积治理或其它独立问题。

## 需求细则

### 网络行为可解释

联网请求经授权后，应在授权范围内访问目标；失败时能区分策略拒绝、代理或上游不可用和目标服务失败。禁止联网的命令仍受限制。不得通过清除代理变量或切换执行身份静默扩张权限。

### 就绪与恢复可信

缺失、不兼容或损坏的初始化状态不能显示为就绪。已观察到的执行环境故障不能仅因旧状态文件仍存在而被清除。修复后需验证本次故障对应能力；网络失败和初始化失败不能互相冒充。

首次初始化、显式修复、普通命令和并发请求的职责应清楚。需要用户动作时只给出与实际状态相符的动作，避免重复触发同一失败。恢复后业务命令是否执行必须有独立结果，原进程状态不明时不得自动重跑有副作用操作。

### 现场诊断可用

诊断应提供初始化助手身份、存在与完整性状态、启动结果、初始化状态摘要、代理来源与拒绝原因，以及相关证据缺口。不得采集账户密码、凭据密文、完整环境或无关用户文件。模块名无法取得时应明确标注未知，不能推测补齐。

## 验收条件

- [ ] AC-1：已授权联网的固定探针可在受管执行路径完成；未授权联网仍被阻断；产品代理与继承代理分别有证据，错误分类可解释。
- [ ] AC-2：状态缺失、错误版本、身份结构不完整和已记录的初始化失败均不会被错误展示为 ready；有效状态可被正确识别。
- [ ] AC-3：初始化成功、失败、取消、并发请求及重启后恢复有明确互斥结果；修复完成后通过对应能力探针；无证据时不宣称业务已恢复或完成。
- [ ] AC-4：配套助手缺失、被替换或无法加载时，校验或诊断能明确报告；正常 frozen candidate 通过对应 capability smoke。
- [ ] AC-5：工具结果、实时状态和历史展示对失败与恢复保持一致；恢复说明指向实际可用的下一步，不能默认切换宿主执行绕过边界。
- [ ] AC-6：新诊断包可关联构建、初始化操作和网络拒绝；导出范围与保留量受限且无敏感载荷；旧包继续可读，缺少历史证据时有明确标记。
- [ ] AC-7：本机机制测试与用户现场结论分开；记录 Windows 10 对应环境验证及用户电脑上“失败 → 修复 → 原操作恢复”的证据。缺少现场结果时不能关闭弹窗问题。
- [ ] AC-8：受影响自动化检查与项目全量检查通过；所需打包等级按项目契约执行，用户明确确认验收完成后才能收口。

## 开放问题

- 用户历史弹窗具体缺失或加载失败的模块仍未知；近期同款弹窗尚无精确时间与路径绑定。
- HTTPS 403 的配置缺陷已确认，但现场具体拒绝原因及是否存在并存的代理问题仍需采集。
- Windows 10 干净环境和用户现场验证尚未执行；不得使用开发机 Windows 11 的成功结果替代。
