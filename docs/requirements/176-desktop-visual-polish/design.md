# 176 · 桌面前端视觉整理方案

CONFIRMED · 2026-11-09

## 聊天首页和侧栏

首页在现有居中问候里写出 AF 的名字。反馈和连接状态固定在聊天区右上角，消息视口从窗口内容区顶部开始。宽窗口沿用居中的正文列，窄窗口为角落控件留出横向空间。反馈图标提供提示与无障碍名称，继续向反馈页传递当前会话。连接正常时右上角只显示反馈图标。连接中和离线时显示对应状态文字。侧栏顶部保留“新对话”，历史分组去掉重复入口。当前行使用主题底色，现有未读、等待和授权标记继续表示会话状态。

## 页头

设置、待办、IM 共用一个展示型页头，统一标题、说明、间距与操作对齐。页头允许换行，由各页决定外层宽度、分隔线和滚动位置。

## 滚动

首批迁移聊天历史、设置主体和待办两栏。每个区域只设一个纵向 viewport，待办筛选与分页按钮位于列表视口之外。滚动条组件集中控制可见滑块宽度和悬停色，保留现有拖拽区域。对于长标题，限制纵向 viewport 内的内容宽度。后续迁移定时任务、记忆和长工具输出时分别核对分页观察器、虚拟列表与内层滚动边界。

## 验证

通过页面与组件测试检查入口、状态和列表结构，在真实 Tauri WebView 查看首页、长历史、同级页头及滚动行为。桌面验收后保留本次 dev 实例供用户复核。
