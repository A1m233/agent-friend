# 内置 PDF、截图 Skills 与执行环境适配

## 状态
CONFIRMED

## 背景与目标
用户要求将 OpenAI 公开的 PDF 和 screenshot Skills 原封不动引入，通过验证明确环境依赖，再完成对应环境适配。用户进一步确认本需求同时覆盖产品自带 PowerShell 7，以及已有相关工具对自带环境的复用。不扩展为新的 PDF 编辑器、桌面控制工具或音频能力。

## 范围
- 完整保留上游 SKILL.md、脚本、metadata、图标和许可证，记录精确来源与内容摘要。
- 验证现有 Skill catalog 的发现与激活，以及依赖、脚本执行和最小产物。
- 区分开源 Skill 的安装说明、当前 Codex Desktop 依赖包和 agent-friend 的运行环境。
- 对齐 Codex Desktop，由产品预置两个 Skill 所需的原生工具和 PDF Python 包，普通用户不应依赖安装 Codex 或首次联网安装这些基础依赖才能获得能力。
- 产品自带 PowerShell 7，现有相关命令、Skill 脚本和进程执行入口统一复用产品提供的环境。
- 不修改系统全局 PATH，不把系统 PowerShell 5.1 命令一律替换，不改变已有沙箱、审批、进程归属与停止语义。
- 保留上游文件原样；默认路径缺陷和项目代码检查冲突优先在宿主调用约定与第三方资源管理边界处理，若必须修改上游内容则重新确认。
- 不新增音频能力、桌面操作能力或与本需求无关的工具迁移。

## 验收条件
- AC-1：引入文件与固定上游版本逐文件一致，包含许可证与所有资源。
- AC-2：两个 Skill 能被产品发现并激活。
- AC-3：在不借用 Codex 运行环境的条件下，按确认的依赖准备方式完成最小 PDF 生成、提取和渲染；清楚区分首次联网准备与离线可用边界。
- AC-4：截图原脚本通过产品提供的环境和正式执行入口产生有效图片；正确处理输出路径、权限与失败，不以退出码替代产物检查。
- AC-5：没有系统 PowerShell 7、PATH 中存在其它版本等场景下，普通 pwsh 调用稳定选用产品版本；用户显式指定外部可执行文件时保留明确路径语义。
- AC-6：沙箱命令、Skill 脚本与宿主进程工具复用同一产品运行时定位；授权、终止、失败归因和原有 Python 会话隔离行为不回归。
- AC-7：盘点并迁移现有相关产品调用、提示和 smoke；不机械替换系统 PowerShell 5.1 或开发机脚本。
- AC-8：依赖版本、来源、完整性与许可证可追溯；执行环境缺失或损坏可诊断，不能静默借用 Codex 或不明环境掩盖缺陷。
- AC-9：项目检查、受影响的冻结 runtime 验证和用户验收完成后才视为可交付；明确跨平台未验证范围。
