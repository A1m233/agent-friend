# 168 · AF 独立游玩中文版宝可梦火红

## 状态

已确认（Confirmed），确认日期：2026-10-31。

## 背景

用户希望在 AF 中提供宝可梦游玩能力，复用已有游戏项目中适合的环境控制能力，由 AF 自己观察、决策和持续推进。本期聚焦独立完成游戏，不建设直播或观众互动。

AF 已有模型图像输入、工具循环、Skill、会话持久化和上下文管理基础；仍需建立游戏操作、连续游玩与恢复的闭环。外部项目的通关记录仅说明方向可行，不构成本产品的速度或成功率承诺。

## 目标

- 用户能够让 AF 从中文版《宝可梦 火红》的新存档开始独立游玩。
- AF 自己完成探索、对话、队伍管理与战斗，直到击败四天王和冠军、首次进入名人堂。
- 支持长时间运行中的暂停、保存、恢复和运行故障处理，留下可复查的过程与结果。
- 实际测量推进速度、等待时间与模型消耗，避免把基础工具接通误报为通关交付。

## 范围

### 包含

- 一个经确认的中文版《宝可梦 火红》版本，优先保持原版剧情与游戏机制。
- AF 内的玩法说明与游戏操作能力；决策使用 AF 的会话与模型能力。
- 首版以 AF 个人 Skill 和独立配套工具交付，暂不作为安装包内置 Skill。
- 纯画面观察、有限批量按键，以及 AF 自己形成的游戏笔记和操作序列复用。
- 新游戏、继续游戏、暂停、停止、保存及故障恢复。
- 中文显示、操作及存档兼容性验证。
- 自动化机制验证、真实游戏验证和一次完整自主通关的证据。

### 不包含

- 直播输出、主播布局、语音解说、弹幕或观众互动。
- 用第三方独立 GPT 玩家代替 AF 决策。
- 向模型提供游戏内存中的隐藏状态、预写通关路线或人工逐步指导。
- 用修改游戏数据、预置通关存档或跳过剧情代替实际通关。
- 全图鉴、二周目、全支线、改剧情或加强难度版本，以及多款游戏通用平台。
- 承诺复现外部项目约 18 小时的成绩，或保证任意模型都能通关。

## 需求

### R-1 · 可识别的中文版游戏基线

- 调研中文版本及补丁来源，确认最终采用版本、基础版本要求和完整性校验值。
- 游戏资源来源、许可与复用边界应可核实；不把游戏 ROM 或未经授权的资源提交到产品仓库。
- 不以英语版兼容性结果代替中文版验证；版本不匹配时说明问题，不静默降级成英文游戏。
- 至少验证开场、中文对话、菜单、战斗及游戏保存和读取。

### R-2 · AF 自主观察与操作

- AF 基于实际游戏画面决定下一步，能执行有界按键序列，并获得操作之后的新画面。
- 观察与操作结果应能关联，区分未执行、执行完成、部分执行、失败和执行结果不确定。
- 只允许一个控制者操作同一游戏实例，避免并发操作相互干扰。
- AF 可记录并复用自己探索得到的信息和操作序列，不向其注入固定攻略或隐藏游戏状态。
- 具体工具、服务边界及纯视觉控制方式在技术方案阶段确定。

### R-3 · 持续推进与恢复

- 不要求用户每一步发送“继续”；AF 能在已批准的运行边界内持续游玩。
- 暂停、停止、预算耗尽与运行故障具有明确状态，不把中断误报为完成。
- 保存与恢复应绑定游戏版本、游戏进展和 AF 的相关上下文，避免拿旧认知操作新存档。
- 网络故障和进程重启后可从有效恢复点继续；动作结果不确定时先重新观察，不盲目重复执行。
- 区分正常游戏失败后继续尝试、运行故障恢复，以及人工改变游戏进展。人工介入与恢复造成的进度回退必须可追溯。

### R-4 · 真实通关与过程证据

- 正式验证从新存档开始，由 AF 完成实际操作与游戏决策。
- 保存运行所用的产品代码、游戏及补丁、模拟器、模型与配置身份，以及起点、恢复点和终点证据。
- 记录有效运行时间、停机时间、模型等待、动作执行、模型消耗和人工介入；未获得的数据标记缺失，不估造。
- 通关由实际冠军胜利与名人堂画面、有效存档及对应执行记录支持，不能只采用 AF 自述。
- 若尚未通关，如实报告进度、失败和剩余问题，不以 demo 或局部 smoke 替代本需求完成。

## 验收条件

- [ ] AC-1：固定并校验中文版基线，中文开场、对话、菜单、战斗及保存/读取均通过真实验证。
- [ ] AC-2：在 AF 中能观察并操作游戏；批量动作有边界，结果包含可关联的实际后续画面，不依赖第三方模型循环代玩。
- [ ] AC-3：纯视觉边界得到验证，模型输入不包含隐藏游戏状态、预写通关路线或人工逐步指导；AF 自己的笔记可保留和恢复。
- [ ] AC-4：无需逐步人工催促即可持续推进；暂停、停止、故障和预算边界正确生效。
- [ ] AC-5：验证保存恢复、进程重启、网络故障和动作结果不确定情形，不静默重复动作或混用游戏与会话状态。
- [ ] AC-6：从新存档完成至少一次 AF 独立通关，保留冠军胜利、首次名人堂及有效存档的关联证据。
- [ ] AC-7：提供真实速度、等待与模型消耗记录，说明停机、恢复、人工介入和证据局限。
- [ ] AC-8：适用自动化检查及项目门禁通过，用户明确确认验收完成。

## 待技术方案确定

- 中文版与补丁的准确来源、版本、许可及本机资源准备方式。
- 第三方项目复用范围与许可证处理，以及模拟器和 AF 的接口边界。
- 长任务、存档与 AF 上下文的恢复方式，动作不确定时的处理机制。
- 正式真实运行所用模型、时长、调用量或费用上限及停止条件。

需求确认不等于无限真实模型调用授权。正式运行前按个人级 LLM API 规则说明配置和粗略调用量，取得对应执行授权；本次尚未运行真实模型。
