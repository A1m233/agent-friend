# 统一会话文件附件 - 技术方案

## 状态

CONFIRMED

## 需求文档

[requirement.md](./requirement.md)

## 现状与边界

附件资产由 AttachmentStore 持久托管，SessionFileService 从有效用户事件发现文件并准备 inputs/ 副本。现有投影仅对 PDF 生成引用，TXT 注入全文，图片通过 provider 原生投递。自定义连接的 images/documents 既控制准入，又间接控制图像工具结果。

## 方案

### 职责分离

- attachments 负责字节托管、文件元数据与应用级准入，不依赖模型的图片或文档能力。
- session_files 负责有效会话引用、校验、工作副本准备与本轮文件信息；复用现有工作目录和配额。
- input_projection 只生成模型视图，不读取正文、不复制文件、不上传，不在预算候选评估中产生副作用。
- Conversation 只在持久输入接受后调用准备边界，不实现路径算法或协议适配；SessionManager/assembly 注入能力。
- llm_providers 负责图像工具结果的协议投影；用户附件不再触发远端文件上传。
- 前端只消费应用级附件准入，文件卡片展示与模型协议解耦。

### 文件接收与准备

取消格式白名单；可信签名识别已知类型，其余保留安全的类型信息或归为 application/octet-stream，未知二进制和非 UTF-8 文本不因不能解析而拒绝。保留大小/数量/配额、文件名清理和内容哈希。

用户事件持久化后、首次模型调用前自动准备本轮全部附件，幂等恢复沿用相同边界。正常新附件提示直接包含 file_ref 和相对路径；历史引用保持来源与恢复入口。准备失败不回滚已接受消息或删除原件，不能投影虚假的就绪状态。完成的幂等重放不重复创建文件。

session_files list/prepare 继续服务历史发现、清理后的恢复及明确重取；活跃消息来源是权限依据，模型摘要不是授权依据。副本路径、同名隔离、只读属性及链接检查复用 SessionFileService。

### 输入投影与预算

所有用户附件统一生成来源明确的文件信息，清空临时模型视图的 attachments，持久 Message 保持原始引用。默认 projector 同样禁止附件正文透传。升级 INPUT_PROJECTION_VERSION，清理 PDF/TXT/native image 的旧预算分类及原件字节成本，保留实际工具图像预算。摘要与任务锚点沿用文件引用语义。

provider adapter 对漏投影的用户附件明确拒绝；删除其原生文档抽取、用户图片上传与专用缓存实现。保留图像工具结果的快照读取和完整性校验。

### 按需图像

view_image 增加会话 file_ref 输入，与原 filesystem_scope_id/path 输入互斥；宿主注入当前会话，以有效用户附件引用授权读取原件，不授予整个工作目录或外部目录权限。图片解码、尺寸限制与快照继续由 ImageReadingService 负责。

Responses 使用现有 function_call_output 图像内容块。Chat 协议由独立请求投影处理：工具结果保留文本及调用 ID，在一组工具结果完整之后附加标明工具来源的图像输入；内部事件仍是工具结果，不伪造成持久用户发言。预算与最终请求使用相同投影，避免漏算或校准漂移。

自定义连接不再手动声明 images/documents。已知内置模型遵守实际视觉能力；自定义兼容协议允许按需尝试图像输入，但不宣称已验证支持。明确的图像不支持错误应有界恢复为可解释的不可用状态，普通鉴权、网络和参数错误不作为能力结论，不增加自动探测或跨模型调用。

### 配置、入口与关联清理

删除自定义模型现行 images/documents 类型和 UI 字段，解码兼容旧字段，保存规范化后不再输出。附件准入保留文件处理运行态与工具调用可用性检查，移除原生格式、数量和大小差异。前端选择/拖拽/粘贴不设置 MIME 白名单，普通文件使用通用卡片。

覆盖编辑重发、历史加载、模型切换、AG-UI、IM 合并与附件解析；移除 GIF 上传拒绝，GIF 可保存但不承诺现有静态看图工具能直接理解动画。IM 语音专用流程保持原责任边界。诊断与资产回收继续按持久附件引用工作，不增加正文日志。

## 验证与风险

- 单测与调用链测试覆盖未知格式、文件大小、自动准备、同名/跨会话/失效引用、旧配置与纯投影。
- provider 请求测试覆盖用户附件不透传、工具图片双协议投影、并行工具事务、错误恢复与预算一致性。
- 桥接及前端测试覆盖所有准入和发送入口，跑 scripts/check 项目门禁。
- 真实 LLM 验证另按逐次授权执行，确定性测试不代表真实模型行为验证；桌面视觉验收另获授权。
- 不新增解析依赖或资源装配方式。复核既有 frozen session_files/image_reading smoke，若实现出现未覆盖的打包高风险路径则按冻结 runtime 规则升档。
