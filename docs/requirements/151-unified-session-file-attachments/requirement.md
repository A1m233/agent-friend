# 统一会话文件附件

## 状态

CONFIRMED

## 背景

142 提供了会话上传文件的发现与工作副本准备，143 将 PDF 改为按需读取。当前 TXT 仍全文注入模型，图片仍随消息原生投递，上传入口和自定义连接仍依赖图片、文档能力声明。用户希望附件统一进入会话工作目录，Agent 按需处理，并清理各入口、设置与历史链路中遗留的原生附件限制。

## 目标

- 任意类型的附件可作为会话文件接收，发送时自动准备到当前会话工作目录。
- 模型默认只获得文件来源、名称和可操作的读取信息；正文和图像仅在任务需要读取时进入模型上下文。
- 用户无需在自定义连接中声明图片或文档附件能力，也不因切换模型而被要求移除已上传文件。
- 新旧附件、桌面与既有 IM 入口采用一致的文件语义，原件持久性和会话隔离不退化。

## 范围

### 包含

- 任意文件类型的上传与本地托管，包括文本、图片、PDF、Office 文件、压缩包和未知二进制类型。
- 文件选择、拖拽、粘贴文件、仅附件消息、混合消息、编辑重发、AG-UI 与既有 IM 普通附件入口。
- 消息发送时自动准备会话工作副本，向 Agent 提供来源明确、可直接使用的文件信息。
- 删除自定义连接的图片输入和文档输入声明，兼容已保存配置。
- 清理按模型原生附件格式进行的准入、模型切换限制、提示、预算估算和失效分支。
- 原生附件投递转为文件引用；保留按需读取结果进入模型的能力。
- 旧会话、上下文压缩、重启、工作副本清理后的恢复，以及同名文件和原件缺失的正确反馈。
- 按需看图与附件接收能力解耦，避免删除设置后意外关闭既有视觉读取链路。

### 不包含

- 保证任意格式均可解析，或为每种格式新增解析器、OCR、音视频理解服务。
- 自动切换模型、跨 provider 转交文件或自动执行上传文件。
- 重做文件管理、复杂预览、会话工作目录和全局上下文管理系统。
- 改变既有 IM 语音消息的专用处理流程。

## 需求

- **R-1 统一接收**：附件接收不再由当前模型原生图片或文档能力决定；各入口使用应用级数量、大小和容量限制。未知格式可保存，不能因缺少解析器被误报为上传失败。
- **R-2 自动就绪**：发送附件后，Agent 可从本轮输入取得可操作的工作文件信息，不需为正常新附件先列举再准备。文件准备失败必须明确反馈，不能把不存在或未校验的副本宣称为可用。
- **R-3 按需投递**：PDF、TXT、图片及其他文件均不随用户消息自动投递正文、原件、Base64 或远端文件引用。实际读取的文本片段或图像可作为工具结果进入后续模型请求。
- **R-4 无手动附件声明**：自定义连接不再要求图片输入、文档输入配置；旧配置可继续加载。读取工具是否可用由实际工具与模型路由能力决定，不能把未知视觉能力当成已验证支持。
- **R-5 持久与恢复**：原件与消息来源关系持久保留。旧附件无需重新上传有效原件，重启与压缩不影响发现和可信重取；失效消息引用不得越过当前会话有效历史边界。
- **R-6 保护与失败反馈**：保留原件校验、会话隔离、同名区分、输入副本保护和容量限制。上传不授予自动执行权限；不能读取的格式、缺少工具、模型不支持视觉、原件损坏和磁盘失败分别如实说明。
- **R-7 预算与来源**：文件方式仅计算实际进入请求的文件信息与读取结果；不再按未读取原件字节估算上下文。历史预算依据随投递方式变化正确失效，文件名与正文仍是数据来源而非系统指令。
- **R-8 关联清理**：同步盘点设置类型、持久化编解码、模型目录、前端上传与发送、桥接协议、IM 特殊拒绝、provider 投递、摘要与任务锚点、测试和现行提示，避免新旧语义并存。

## 验收条件

- [x] **AC-1**：代表性的文本、图片、PDF、Office、压缩包和未知二进制可经普通附件入口接收；不依赖自定义图片或文档声明。
- [x] **AC-2**：正常发送后本轮文件自动在当前会话工作目录就绪，模型获得来源和可读取信息；覆盖仅附件、多个同名文件和混合类型。
- [x] **AC-3**：首轮、续轮和历史重放的 provider 请求不自动包含附件正文、图像或远端文件 ID；按需读取结果可正常进入后续请求。
- [x] **AC-4**：自定义连接两个声明项从界面及现行配置契约移除，旧配置兼容；模型切换不再按原生附件类型阻止发送。
- [x] **AC-5**：既有受支持视觉路由仍可按需读取图像；不支持或无法确定能力时反馈明确，不伪造视觉理解。
- [x] **AC-6**：覆盖桌面、AG-UI、编辑重发与 IM 普通附件，清理 GIF 等格式特殊拒绝和过时提示，IM 语音专用链路不回归。
- [x] **AC-7**：重启、压缩、旧会话、工作副本清理后可恢复；原件缺失、损坏、越权引用、路径冲突和容量不足有确定性验证。
- [x] **AC-8**：预算只计实际文件信息和读取结果；文本大文件不会因全文自动注入而超窗，旧计量依据不会错误沿用。
- [ ] **AC-9**：关联盘点有实现或保留理由记录，受影响测试和项目检查通过；真实模型、桌面与跨平台验证如实标注，用户确认验收完成。
