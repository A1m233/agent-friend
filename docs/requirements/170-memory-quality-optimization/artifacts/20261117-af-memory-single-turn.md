## 写入和核验

3 笔成功事务含 7 项操作，作用于 6 个不同的旧 ID。5 个普通事实中，1 个被撤销，4 个被撤销后分别写入一条替代事实。重复经历中的 1 个 ID 先按原话补全地点，再并入同一回合的保留项。最终库相对起点有 10 条记忆行发生差异。独立读回核对了所有受影响行、5 个普通事实变更组及成员。全部差异与 AF 提交的事务相符。SQLite 完整性、外键和两层全文索引检查通过。

- **来源归属得到纠正。** 例如，用户让助手核实一条标题，旧事实把核实结果归给了用户。替代文本区分了用户的请求与助手随后给出的判断。
- **长期层准入仍有问题。** 4 条替代事实均保留了有日期的一次性对话或任务经过。其中明确包括一次识图、一次待办标记。它们纠正了归属或时效，但作为普通事实长期保留的价值仍缺依据。
- **两项尝试未生效。** 一条同义兴趣推断因重新查证时原话不可用仍有效。另一条旧提醒的完成证据来自后续回合，冻结写口未接受该跨回合证据。该写口也只允许同文的精确合并，AF 为此在一组经历上先做改写再合并。
- **与此前人工审计的交集。** 先冻结 AF 决策，再核对旧计划的 58 个普通事实目标、8 个经历目标。AF 收到其中 7 条普通事实的正文，对 3 个读取详情和原话，最终命中 1 个相同目标且处置一致。另外 5 个实际修改目标来自她自行发现的问题。旧计划内的经历目标均未进入本轮模型请求。

### 最后一轮为何终止

最后一页普通事实返回了下一页起点 129，经历和退役历史也有下一页。AF 转向已发现的问题。最后一个工具批次中，详情与库存查询成功。AF 随后想按 4 个新写入的替代 ID 再查原话，隔离证据工具拒绝了这次请求。它要求目标曾出现在冻结库存的分页结果中，而新 ID 都在快照之后产生；尽管能用写入回执打开详情，这 4 个 ID 无法通过该证据检查。工具限制只影响新 ID 的查证，已有库存仍可继续翻页。

第 20 次模型调用仍收到 8 个工具。AF 返回部分完成的报告，没有发出新的翻页请求。原生会话在模型交回文字且没有工具调用时记录正常 `end_turn`，结束前没有全库覆盖率校验。日志能确认这个顺序和可用能力；不能断定最后一次查证失败单独导致了模型收尾。
