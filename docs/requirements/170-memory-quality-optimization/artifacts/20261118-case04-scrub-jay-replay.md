这轮的归属判断在 20 次中均正确。值得讨论的是两处取舍：已有原论文和专门笔记时，日后可能引用能否单独构成普通事实的准入依据；一次自主发现值得作为经历回顾时，方法、结果和存笔记动作是否各有独立的回顾价值。本次测量只覆盖此固定回合与一个提示词版本。

第 08 次在第一条经历记录实验测量的是鸟去哪里找，第三条经历描述存笔记时又重复了这个区别。另有 12/20 条普通事实进一步写下 AF 对实验的解读，即两组的差别很难仅用遗忘藏食位置来解释。
