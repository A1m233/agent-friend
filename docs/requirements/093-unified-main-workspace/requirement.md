# 统一主窗口与内容导航

## 状态

CONFIRMED

## 背景

agent-friend 当前把对话、设置、IM 接入和 Memory Inspector 分散在多个独立桌面窗口中。随着设置分类、反馈与诊断、IM 绑定和记忆调试能力逐渐增加，桌宠 ActionBar 正在承担越来越多的窗口启动职责，用户也需要在多个普通内容窗口之间反复切换。

现有对话窗口已经具备稳定的两栏结构：左侧用于搜索、新建和切换会话，右侧用于展示当前对话内容。相比继续增加独立窗口，更自然的产品结构是把它扩充为统一主窗口，由左侧承担主内容导航，右侧承载不同内容页面。

桌宠、气泡和语音通话具有独立的桌面交互形态，不属于普通内容页面，不应因本次整合而改变。

## 目标

- 将现有对话窗口升级为统一主窗口，在一个窗口内访问新对话、历史会话、设置、IM 接入和当前本地 capability 允许使用的 Memory Inspector。
- 把左侧现有“新对话”所在区域扩展为固定内容切换区，并以与会话一致的选中态表达当前所在位置。
- 把右侧现有对话区域扩展为统一内容展示区，根据左侧选择展示对应的原有内容。
- 保留对话页面现有的布局和专属样式层，避免统一外壳影响已经稳定的对话视觉与交互。
- 保留桌宠 ActionBar 的外观、按钮顺序和使用方式，只改变相关按钮打开内容的位置。
- 减少普通内容窗口之间的切换，同时不改变桌宠、气泡和语音通话的独立窗口形态。

## 范围

### 包含

#### 1. 统一主窗口

- 现有对话窗口成为统一主窗口。
- 左侧保留搜索入口，并在搜索入口下方提供固定内容切换项：
  - 新对话
  - IM 接入
  - 设置
  - 记忆面板（沿用当前本地 capability gate；开发构建默认开启）
- 固定内容切换区下方继续展示现有会话列表及其状态、IM 标记和操作能力。
- 右侧作为统一内容展示区，展示当前选中的页面或会话。

#### 2. 统一选中态

- 任一时刻，左侧只显示一个与右侧内容对应的选中项。
- 进入新对话首页时，“新对话”呈现选中态。
- 进入某段历史会话时，对应会话呈现选中态。
- 进入设置、IM 接入或记忆面板时，对应固定入口呈现选中态，历史会话不再显示选中。
- 从搜索结果打开会话后，统一切换到该会话并更新选中态。

#### 3. 右侧内容展示

- “新对话”继续展示现有新对话首页和输入能力。
- 历史会话继续展示现有消息列表、运行状态、授权提示和输入能力。
- “设置”展示现有设置中心的全部分类、内容和帮助与反馈页面。
- “IM 接入”展示现有 IM 接入、绑定和状态管理内容。
- “记忆面板”展示现有 Memory Inspector 的记忆列表、召回 trace 和 probe 能力。
- 现有对话内容及其专属样式层保持完整；统一主窗口只提供顶层内容区域，不把对话专属样式变成全局样式，也不让其他内容页受到对话样式影响。
- 各内容页在统一主窗口支持的窗口尺寸下应保持可阅读、可操作，不出现关键内容不可达或被永久裁切。

#### 4. 会话连续性

- 从会话切换到设置、IM 接入或记忆面板时，不清空当前会话的消息、草稿、运行状态或授权状态。
- 从其他内容切回会话时，可以继续原会话。
- 点击“新对话”仍执行现有的新对话语义，不把它降级为只切换视觉页面。
- 桌宠上的“打开对话”入口优先返回最近使用的有效会话；没有可恢复会话时进入新对话首页。

#### 5. 现有入口改为主窗口导航

- 桌宠 ActionBar 的视觉、按钮、顺序和分页行为不变。
- ActionBar 中的设置、IM 接入和记忆面板按钮改为唤起统一主窗口并导航到对应内容。
- 对话中的“反馈问题”、权限恢复、模型与凭据配置等现有设置深链，改为导航到统一主窗口内的对应设置分类或目标位置。
- 系统托盘和其他现有“打开对话”入口继续唤起统一主窗口。
- 系统托盘右键菜单调整为适配统一主窗口的快捷入口：打开 agent-friend、新对话、IM 接入、设置、帮助与反馈、显示或隐藏桌宠、退出 agent-friend；使用分隔线组织主动作、内容入口、桌宠控制和应用生命周期。
- “显示桌宠 / 隐藏桌宠”根据当前桌宠窗口可见性显示单一明确动作，不再使用含混的“显示/隐藏桌宠”。
- 双击托盘图标与“打开 agent-friend”菜单项行为一致：唤起统一主窗口并进入对话 surface，返回最近有效会话或新对话首页。
- 单击托盘图标不弹出菜单；托盘菜单由右键打开。
- 设置、IM 接入和 Memory Inspector 不再作为面向用户的独立普通内容窗口出现。

#### 6. 保持独立的窗口

- pet 桌宠窗口保持独立。
- bubble 气泡窗口保持独立。
- voice-call 语音通话窗口保持独立，本需求不改变其打开、聚焦、通话和关闭行为。

### 不包含

- 不把语音通话合入统一主窗口。
- 不修改桌宠 ActionBar 的视觉、按钮顺序、分页或交互形态。
- 不重新设计设置、IM 接入、Memory Inspector 或对话页面的业务内容。
- 不重新分类设置中心中的“已归档对话”等现有设置项。
- 不改变 Memory Inspector 现有的本地 capability gate，也不新增记忆功能。
- 不改变 pet、bubble 的透明、置顶、鼠标穿透、位置或生命周期行为。
- 不借本需求改造后端会话、IM、设置、记忆或语音协议。

## 关键信息

- 主窗口结构以用户提供的现有对话窗口截图为基线：左侧是搜索、固定切换区和会话列表，右侧红圈区域是统一内容展示区。
- 现有对话页面的布局与样式已经稳定，本需求必须通过清晰的内容边界复用，不能用全局样式重写或扁平化合并。
- 现有设置中心具有自己的分类导航；嵌入主窗口后仍保留该内部导航和全部现有页面。
- Memory Inspector 继续沿用现有本地 capability gate：开发构建默认开启，正式构建只有显式 owner capability 开启时可见。
- 关联现有需求：
  - `010-desktop-shell-and-chat-ui`
  - `019-pet-actionbar-rework-and-settings-shell`
  - `022-im-channel-qqbot`
  - `026-memory-inspector`
  - `028-settings-center-and-cross-window-sync`

## 验收条件

- [ ] 打开主窗口后，左侧能看到搜索入口、新对话、IM 接入、设置；开发模式下还能看到记忆面板。
- [ ] 点击“新对话”，该入口呈现选中态，右侧显示现有新对话首页和输入框。
- [ ] 点击任一历史会话，只有该会话呈现选中态，右侧显示对应会话内容。
- [ ] 点击设置、IM 接入或记忆面板，只有对应固定入口呈现选中态，右侧展示对应的原有内容，会话行不保持选中。
- [ ] 从全局对话搜索结果打开会话后，右侧切换到该会话，左侧对应会话呈现选中态。
- [ ] 从会话切换到其他内容再返回，会话消息、草稿、运行状态和待处理授权未被误清空。
- [ ] 设置中心全部现有分类与帮助反馈均可在右侧内容区使用；来自反馈、权限、模型与凭据入口的深链能定位到正确设置目标。
- [ ] IM 接入的现有连接、绑定、解绑和状态展示能力可在右侧内容区使用。
- [ ] 本地 capability 开启时 Memory Inspector 的现有记忆浏览、召回 trace 和 probe 能力可在右侧内容区使用；未开启时不显示入口。
- [ ] 对话内容的现有布局、滚动、输入区和专属样式未被设置、IM 或记忆页面的样式破坏，其他内容页也不受对话专属样式污染。
- [ ] 桌宠 ActionBar 的视觉、按钮顺序和分页行为不变；设置、IM、记忆和对话按钮能唤起主窗口并导航到正确内容。
- [ ] 托盘右键菜单按确认顺序提供打开 agent-friend、新对话、IM 接入、设置、帮助与反馈、动态桌宠显隐和退出入口，并以分隔线分组。
- [ ] 托盘“新对话”唤起主窗口并执行现有新对话语义；设置、IM 和帮助与反馈定位到主窗口中的正确内容。
- [ ] 托盘桌宠显隐项根据当前可见性显示“隐藏桌宠”或“显示桌宠”，执行后同步更新。
- [ ] 双击托盘图标与“打开 agent-friend”一致地唤起主窗口对话 surface；单击不弹出菜单，右键打开菜单。
- [ ] 桌宠“打开对话”优先返回最近使用的有效会话，没有可恢复会话时显示新对话首页。
- [ ] 设置、IM 接入和 Memory Inspector 不再打开独立普通内容窗口。
- [ ] pet、bubble 和 voice-call 仍保持独立窗口，语音通话行为无回归。
- [ ] 主窗口在支持的最小尺寸下，各页面关键内容均可访问，无永久裁切或无法操作的控件。
