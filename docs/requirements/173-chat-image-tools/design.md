# 173 · 聊天图片工具技术方案

## 状态
CONFIRMED。用户确认方案并授权实现。

## 需求
[聊天生图与连续改图](./requirement.md)

## 实现
- 工具以 `imagegen` 注册。沿用 AF 工具运行、取消和进度事件。提示词、透明背景与最多五张参考图是模型可见参数。指定来源可为会话 file_ref 或当前轮已获 read_image 授权的文件；取最近图片时只使用活动会话中的图片。
- 在模型执行快照中携带图片请求的同连接地址、凭据与可选模型 ID；自定义连接的新增配置向后兼容。兼容连接在用户实际调用时按生成和编辑分别处理。图片模型为空则省略 model。内置来源须有明确适配才提供独立图片工具。
- llm_providers 处理兼容 Images 协议。生成传 JSON，编辑以 multipart 发送实际参考图。约束响应大小，拒绝跨地址跳转或下载任意结果 URL。分别反馈操作不可用、模型需要配置、鉴权、限流、服务故障和无有效图片。取消、超时及结果未知均不自动重新发送图片请求。
- agent 负责参考来源和产物归属。成功的工具结果携带应用托管附件，工具结果和助手图片事件一起持久化；模型收到可引用的文字凭据。使用现有实时及历史助手图片展示，避免再在工具卡显示同一张图。已有 hosted image_generation 路径与历史保留。
- 设置沿用连接编辑界面，图片模型为可选项；切换连接后绑定该连接的配置。旧连接无需迁移。验证用假上游覆盖协议和失败边界，用独立 CPA 走 AF 的真实生成、改图、会话重载；项目门禁覆盖各入口。
