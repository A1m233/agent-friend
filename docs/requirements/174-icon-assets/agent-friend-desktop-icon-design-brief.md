# agent-friend 应用与托盘图标设计委托书

请为 agent-friend 桌面应用提供一套图标。用户需要在桌面找到应用、在安装时认出它，并在应用运行后从系统托盘找到它。应用主图标和托盘图标要能被认作同一款产品。具体图形、配色、风格以及小尺寸下如何简化，均由设计方决定。

## 请交付两项资产

| 资产 | 使用场景 | 交付文件 |
| --- | --- | --- |
| 应用主图标 | 桌面快捷方式、应用列表和 Windows 安装器共用。 | 一份正方形可编辑 SVG 母稿，以及从该母稿导出的 1024 × 1024 px PNG。 |
| 系统托盘图标 | 在系统任务栏或菜单栏的小图标区域显示，需要在浅色和深色背景上都能辨认。 | 一份适合小尺寸显示的可编辑 SVG。若浅、深背景需要不同版本，请分别提供并注明适用背景。 |

## 请附一张原尺寸预览图

在浅色和深色背景上分别排一行。每行放置 **32、128 px** 的主图标和 **16、24、32 px** 的托盘图标，标注尺寸。请按实际像素排版，背景色仅用于预览。

我们会按 100% 比例查看这张图。主图标缩到 32 px 时应能认出与大图相同的标识；托盘图标在 16 px 时关键笔画和间隙仍能分辨，外轮廓在两种背景上都清楚。正式文件保留设计本身的底色，其余画布区域透明。

## 回传方式

请将主图标 SVG、1024 px PNG、托盘 SVG（含适用的变体）及预览图一起打包回传，文件名标明用途。SVG 应可独立打开；如用到文字，请转为轮廓。收到资产后由我们生成平台所需的 ICO、ICNS 和其他尺寸 PNG，并在实际使用位置验证。
