# 桌面应用与系统托盘图标接入

## 状态

CONFIRMED

## 资产与构建

[需求](./requirement.md)选定的原稿随桌面壳保存。用项目锁定的 Tauri CLI 从设计方的 1024 px PNG 生成平台图标，更新现有桌面 PNG、ICO 和 ICNS。NSIS 的 `installerIcon` 与应用共用 `icons/icon.ico`。安装和运行时都从随产品构建的资源读取。

## 原生托盘

在现有 `setup_tray` 中嵌入 16、20、24、32 px 托盘 PNG。按系统小图标所需物理尺寸选取相符或稍大的图像；超过 32 px 时复用较大尺寸的应用主图。显示缩放变化时更新托盘，深浅背景共用同一文件。沿用现有菜单、工具提示、点击和退出行为。

2026-11-09 修订：原方案按背景切换像素头像；用户改选原图尺寸版后移除背景判断、旧头像及专用配色依赖。

2026-11-10 定稿：保留交付的 1024 px 母稿，从左上坐标 (41, 28) 截取 940 × 940 px 再生成桌面与托盘资产。使用同一取景，完整保留耳尖和脚。

## 验证

检查运行时引用、平台格式、透明区域和尺寸映射。安装器和应用共用同一 ICO。此前隔离安装版用于验证安装链路；最终取景在 Tauri dev 的 Windows 托盘与任务栏中验收，详见[进度](./progress.md)。
