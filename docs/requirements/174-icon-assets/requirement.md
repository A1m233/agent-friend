# 桌面应用、Windows 安装器与系统托盘图标

## 状态

CONFIRMED

## 背景与目标

用户从安装文件、桌面快捷方式或应用列表打开 agent-friend，应用运行后又会从系统托盘找到它。三个入口统一使用设计方的 v5 手绘全身原画，保留同一取景、五官、服饰和颜色。

## 已选资产与范围

| 使用位置 | 已确认的资产 | 期望效果 |
| --- | --- | --- |
| 桌面应用、快捷方式及应用列表 | 手绘 v5 应用主图标 | 在常见显示尺寸上都能认出同一个白发狼耳角色。 |
| Windows 安装器 | 与应用相同的手绘主图标 | 用户在文件管理器看到安装程序时，能认出它与安装后的应用属于同一产品。 |
| 系统托盘 | v5 完整原画，含 16、20、24、32 px 原尺寸导出 | 深浅背景使用同一图案；保留全身构图与透明留白，随显示比例选择尺寸。 |
