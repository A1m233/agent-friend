# Windows 沙箱失败现场与诊断包按轮次采集 — 技术方案

## 状态

CONFIRMED

## 需求文档

[requirement.md](./requirement.md)。用户于 2026-09-14 确认整体方案、默认最近 10 轮与超大内容保护，并授权开始实现。

## 现状与边界

现状证据见 [evidence-index.md](./evidence-index.md)。故障摘要、现场采集、会话采集和 ZIP 消费分开负责；不改变模型工具权限或自动执行系统修复。历史客户事故的具体根因仍未知。

## 方案设计

### 沙箱事故

- 在 command_runtime 下新增专用证据模块，采集错误分类、原生码、状态检查明细、组件指纹与有界底层日志事实。仅白名单输出，不复制 users secrets、任意错误正文或命令输出。
- 每次启动、文件准备及显式修复建立操作标识与前后观察。错误报告、状态文件及日志候选带修改时间／变化证据；报告未变化、时间不属于本次或存在并发时，不断言唯一归因。
- helper_incomplete 展开 marker/users 的存在、读取、解析、结构与版本检查。底层日志按固定错误码、阶段信号和原生码提取；未知消息不原样导出。实际助手启动路径无法从上游证明时明确标记，仅把期望组件指纹当作安装侧证据。
- 独立事故文件位于规范 log_dir 下的 command-runtime-incidents；每项最多 128 KiB、最多 32 项、保留至多 30 天，总内容预算 4 MiB。数量／年龄上限取先到者；正常健康事件不消耗该预算。写入使用临时文件、同步和原子发布，失败不影响原始业务错误传播。
- 修复开始前持久化现场与关联事故 ID，结束追加实际执行路径及探针结果；跨重启仍保留失败与恢复记录。修复不重放原业务。
- Python 在线快照与 Tauri 离线读取使用同一事故文件格式；Bridge 不可用时仍附带已持久化事故并标明当前健康快照不可用。

### 最近 X 轮

- 默认最近 10 轮，X 为 1～100 的整数，另设全部选项。每个所选会话分别应用；不选会话仍能导出系统证据。
- 新增诊断专用只读采集接口，由 SessionStore 负责规范路径与固定文件快照。最近模式逆向扫描 JSONL，按当前有效 user_message/system_trigger 轮次定位，处理中途 turn_rewrite 的失活集合；当前未完成轮次计入并明确只含已持久化部分。
- 选中范围内保留原始业务证据和工具请求／结果，不通过聊天 active 分页替代。会话元信息独立保留；范围外 rewrite/compaction 引用保持引用与缺口说明，不向前递归拉回历史。
- rollout/model transcript 等嵌套历史快照仅保留内容无关摘要，provider continuation 内容删除；防止最近一轮再次携带全历史。全部模式表示全部轮次的诊断投影，仍服从相同隐私与体积保护。
- 单次会话扫描最多 64 MiB、单行解码最多 4 MiB、会话输出最多 16 MiB。超过预算保留可用证据并在 coverage 中报告；不得宣称完整采集，也不阻断系统证据。使用分块读避免超大行占用无界内存。
- 返回请求轮数、实际轮数、开始／结束事件、快照边界、读取字节、输出字节及遗漏类型。附件仅从最终纳入的业务事件派生。
- Tauri 逐会话采集专用响应，取消 full+active 双重传输；在生成结果中报告 partial，界面说明范围和大内容保护。

### 契约与消费者

- formatVersion 保持 1，提升 schemaRevision 与相关 capability；旧能力 handler 保留，新能力有真实摘要与校验。
- 会话文件维持 events 数组并新增 coverage；独立事故单独 entry，避免依赖聊天文件或在线 runtime。
- 消费者输出范围、事故数、失败类别、修复关联和采集缺口，不打印私密正文。

### 验证与性能

- 用确定性故障样本覆盖底层错误分类、报告新鲜度、状态文件各错误、异常退出、留存、修复、并发归属及导出消费。
- 长会话样本固定最后 10 轮，扩大旧历史至少 10 倍；最近模式读取量与输出量不随旧历史线性增长，输出不含旧历史标记。记录冷态耗时、扫描字节与包大小；耗时作观察指标，读取边界和输出大小作稳定断言。
- 超大单轮、损坏尾部、重写、压缩、未完成轮、多个会话与旧包均有契约测试。
- 执行 backend/frontend/Rust 项目门禁，增加冻结运行时高风险路径验证。Windows 10 环境不可用时保留未验证项，不以 Windows 11 代替。
- 未获额外真实桌面视觉验收授权前，仅执行静态与自动化 UI 检查。

## 影响与风险

源 JSONL 在读取时固定长度并检查截断／替换；读取范围外无法验证的历史损坏不声称已检查。无效／超大边界导致 partial，不能猜测轮数。底层未提供的加载原因依然标记缺口；本需求不虚构通用系统追踪能力。
