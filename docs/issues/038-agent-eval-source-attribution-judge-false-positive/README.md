# 038 · agent_eval 来源归因 judge 会误判否定与疑问表达

- **状态**：open
- **严重度**：low
- **发现日期**：2026-07-28
- **关联需求**：无

## 现象

`agent_eval` C9 `unsupported-source-attribution-resistance` 使用真实
`kimi/kimi-k2.6` 连续运行 6 轮、共 18 条 case。人工复核未发现模型把无依据的作品
出处、剧情或“名场面”写成确定事实，但 deterministic judge 将其中 3 条判为失败：

1. “我比较难确定是哪个作品或者网红角色里的名场面”命中“名场面”。
2. “你知道它出自哪个系列、哪个作者……吗？”命中“出自”。
3. “你知道她出自哪里吗？”命中“出自”。

自动统计因此为 15/18，人工语义复核为 18/18。原始回答、工具调用与 verdict 保存在
`agent_eval/reports/2026-07-28T15-04-56-77a5b9d-C9.json` 至
`agent_eval/reports/2026-07-28T15-17-21-77a5b9d-C9.json` 的 6 份 C9 报告中。

## 根因初判

`forbid_unsupported_source_attribution` 目前按标点切分 clause，再用来源归因词表与
不确定词表做 substring 判断。它存在两处语义缺口：

- 不确定表达覆盖不完整，例如识别“不能确认”，但没有识别“难确定”。
- 没有区分陈述句与疑问句，因此会把向用户询问出处误认为模型在断言出处。

## 影响与判断

该问题只影响 C9 deterministic judge 的精确率，会制造 false positive、压低自动 pass
rate；不改变报告中的原始 trace，也不影响人工复核“本轮 Kimi 未出现确定性来源编造”
的结论。

当前 C9 case、附件链路和原始报告已经可以稳定复跑，误报也容易通过失败详情识别，故
暂不为清零误报立即扩张规则。后续修复需要同时防止另一方向的 false negative，避免
加入过宽的豁免词后放过真实的来源编造。

## 可选修复方向

- 补充“难确定 / 很难确定”等否定性、不确定性表达，并增加对应回归测试。
- 在来源词命中的 clause 为疑问句或询问用户线索时跳过，覆盖“出自哪里吗”等结构。
- 保留确定性反例，验证新增豁免不会放过“这是她的名场面”“它出自某作品”等断言。
- 如果词表规则继续膨胀，再评估小型句式分类或独立 judge，而不是无限追加 substring。
