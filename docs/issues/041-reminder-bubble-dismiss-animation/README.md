# 041 · 提醒队列关闭动画存在跳变且观感不佳

- **状态**：open
- **严重度**：low
- **发现日期**：2026-08-04
- **关联需求**：070-todo-management-and-reminders

## 现象

桌宠短气泡同时展示多条提醒时，关闭其中一条可见提醒会出现明显跳变，剩余气泡的位置变化不够连贯，退出动画本身的观感也不理想。

复现步骤：

1. 在开发版桌宠操作栏连续点击“加入提醒队列”，生成至少两条提醒气泡。
2. 关闭任意一条当前可见提醒。
3. 观察被关闭气泡的退出过程，以及其余气泡补位和原生气泡窗口缩放时的视觉变化。

## 根因初判

待定位。目前怀疑是以下生命周期之间缺少协调：

- Sonner toast 的退出动画仍在执行；
- Zustand 队列已经同步删除对应条目并触发其余气泡重新布局；
- `MutationObserver` / `ResizeObserver` 随即重新测量，Tauri 原生气泡窗口提前缩小。

需要通过真实桌面端 DOM、动画时序和窗口尺寸日志确认，不能仅凭当前视觉现象认定具体根因。

## 影响与判断

问题影响提醒队列的关闭体感与视觉完成度，但目前没有证据表明会丢失提醒、错误关闭其他条目或破坏队列补位语义，因此按低严重度体验瑕疵登记。

本轮需求先保证多提醒不互相覆盖、最多展示四条且溢出不丢失；关闭动画的进一步打磨延后处理，不阻塞需求 070 当前交付。

## 可选修复方向

- 在 Sonner 退出动画完成后再从业务队列彻底移除条目或缩小原生窗口。
- 将“业务队列删除”“toast 退出”“可见栈补位”“原生窗口 resize”拆成明确的阶段，避免同一帧抢跑。
- 调整退出和补位的 duration / easing / transform，使多条气泡的运动方向和节奏一致。
- 为原生窗口尺寸变化增加短暂保留或动画期间的尺寸下限，避免阴影和退出中的 toast 被窗口边界截断。
